1. Open Agent Leaderboard

为什么重要

当前 AI 代理（Agent）评估主要关注底层模型的基准测试分数，忽视了代理系统本身的架构设计差异。IBM Research 与 Hugging Face 联合发布的 Open Agent Leaderboard 首次将完整代理系统（而非仅模型）纳入评估，同时报告质量与成本，为行业提供了一个更公平、更有实际指导意义的评估框架。

关键要点

  • 代理系统而非仅模型被评估：Top 3 均使用同一底层模型，但得分和成本差异显著——证明代理架构本身对结果有实质影响

  • 通用代理已具备竞争力：在多个基准测试中，未经特定任务调优的通用代理能匹配甚至超越专门构建的任务专用系统

  • 失败成本不容忽视：失败运行的平均成本比成功运行高出 20%~54%，失败行为模式直接影响生产部署成本

  • 工具筛选（Tool Shortlisting）是关键优化：帮助代理聚焦相关工具而非穷举所有工具，在所有测试模型上都提升了性能

  • 开源全链路发布：Leaderboard、Exgentic 评估框架及完整论文同步开源，支持社区复现和贡献

3. Open Agent Leaderboard：评估使用工具的模型

为什么重要

工具使用能力是 AI 代理的核心竞争力之一，但现有基准测试缺乏对代理使用工具实际效果的评估。Open Agent Leaderboard 对不同模型在使用工具时的性能、效率和失败模式进行了系统性研究，为企业选型和代理架构设计提供了关键参考。

关键要点

  • 工具使用效率差异显著：同一模型在不同代理架构下，使用工具的准确率和成本差异最高可达 3 倍

  • Tool Shortlisting 效果显著：帮助代理在调用工具前先筛选相关子集，在所有测试模型上都带来性能提升

  • 失败模式分析的价值：了解代理何时以及如何失败，比单纯追踪成功率更能指导系统优化

  • 开源评估框架：Exgentic 框架支持社区复现任何模型的代理评估，促进行业透明度和标准建立

4. The Inference Shift

为什么重要

Ben Thompson 在这篇文章中提出了一个具有颠覆性的观点：随着 AI 代理（Agent）真正落地，「代理推理」与「回答推理」有根本不同的架构需求。这将深刻影响 GPU 厂商的战略优势、中国芯片竞争地位，甚至太空数据中心的可行性。

关键要点

  • 两种推理的本质差异：回答推理（人类在循环中）需要低延迟；代理推理（无人类参与）需要大容量记忆层次结构，延迟相对次要

  • GPU 在代理推理中的困境：prefill 和 decode 之间交替运行导致两种资源交替闲置

  • Cerebras 的机会：WSE-3 拥有 21 PB/s 带宽（是 H100 的 6000 倍），极度适合高速回答推理

  • 代理推理将「解绑」GPU：未来架构将以高容量、低成本内存为主，「够用」的算力配合快速 CPU 处理工具调用

  • 对中国的影响：中国拥有完整的「够用」芯片+DRAM+硬盘组合，非常适合代理推理

5. Amazon Bedrock 高级提示词优化工具

为什么重要

企业在迁移到大语言模型或优化现有提示词时，往往依赖人工反复调试，既耗时又难以规模化。Amazon Bedrock 推出的 Advanced Prompt Optimization 实现了提示词优化的自动化闭环——支持同时对比最多 5 个模型的优化效果，大幅降低模型迁移和性能调优的门槛。

关键要点

  • 自动化提示词优化流程：输入提示模板、示例数据、标准答案和评估指标，系统自动迭代优化

  • 多模型并行对比：支持同时评估最多 5 个推理模型，方便跨模型迁移

  • 三种评估方式：Lambda 函数（自定义评分）、LLM-as-a-Judge（评判模型）、Steering Criteria（自然语言优化方向）

  • 多模态支持：支持 PNG、JPG、PDF 作为提示模板输入变量

  • 现已上线：在美东、美西、亚太、欧洲及圣保罗等多区域可用
