模型与基础设施

1. Tenstorrent Galaxy Blackhole AI 系统正式发布

Tenstorrent 宣布其 Galaxy Blackhole AI 系统正式全面上市。该系统面向大规模 AI 推理和训练场景，旨在为 AI 基础设施提供替代方案，挑战英伟达的垄断地位。Jim Keller 领导的团队一直倡导开源硬件和 RISC-V 架构，本次发布是其商业化进程的重要里程碑。

为何重要：Blackhole 系统的高能效架构和开源策略可能重塑 AI 芯片市场格局，为追求供应链多元化的企业提供新选择。

📰 HPCwire

2. AMD GAIA 0.17.5 发布：Gemma 4 成为默认模型

AMD 发布 GAIA（Generative AI Is Awesome）0.17.5 版本，将默认模型从 Qwen 3.5 35B 更换为 Google 的 Gemma 4 E4B（4.5B 参数，128K 上下文窗口，Apache 2.0 许可）。新版本原生支持多模态，并增加了轻量级 Chat Lite Agent 和代码语义搜索功能。

为何重要：Gemma 4 的单一模型方案降低了多模型协调的复杂性，同时 Apache 2.0 许可使其成为企业本地部署的更友好选择。

📰 Phoronix

3. GPT-5.5 和 Claude Opus 4.7 持续迭代

OpenAI 和 Anthropic 均在近期发布了各自旗舰模型的最新版本。GPT-5.5 主打复杂编码、研究和数据推理能力；Claude Opus 4.7 则在软件工程任务上有显著提升。

为何重要：两大巨头持续快速迭代，推动 AI 能力边界不断扩展，同时也让企业在模型选择上更加纠结。

Agent 商业与支付基础设施

4. MoonPay 推出 MoonAgents Card：AI Agent 的加密支付万事达卡

MoonPay 于5月1日推出 MoonAgents Card，这是一张虚拟万事达借记卡，允许授权的 AI Agent 代表用户直接从链上稳定币余额消费，适用于任何接受万事达的在线商户。该产品与 Exodus 和 Monavate 合作开发，通过 MoonAgents CLI 和工作流进行管理。

为何重要：这是首次有主流支付服务商推出专为 AI Agent 设计的可编程消费工具，解决了 Agent 经济中"无法实际花钱"的核心瓶颈。万事达卡的参与表明主流金融网络对 Agent 经济持开放态度。

📰 Startup Fortune

5. Experian 推出 Agent Trust 服务：验证消费者与 AI Agent 的身份链接

信用报告巨头 Experian 发布 Agent Trust 服务，帮助在 AI Agent 商业交易中建立可验证的消费者与 Agent 身份链接。该服务使用"了解你的 Agent"框架，确保 Agent 发起交易的背后有经过验证的消费者身份。

为何重要：信任基础设施是 Agent 经济规模化的前提。Experian 的入局表明传统信用机构正在积极为 Agent 商业场景做准备。

📰 Digital Transactions

6. Kite 发布 Agent Passport：AI Agent 的身份与支付工具包

Kite AI 发布 Kite Agent Passport，为 AI Agent 提供可编程、安全的钱包来持有资金并代表用户消费，同时由用户控制消费限额和授权购买目标。目前正与 PayPal 和 Shopify 进行测试集成。

为何重要：Agent 支付基础设施正在快速形成生态，从 MoonPay 到 Kite，多个玩家正在争夺"Agent Visa/Mastercard"的地位。

📰 Digital Transactions

7. Nansen 预测：2028 年 AI Agent 将成为加密投资默认方式

区块链分析平台 Nansen 预测，到2028年，大多数人投资加密货币的方式将从手动选币变为由 AI Agent 自主代理执行。Agent 将自动监控市场、管理风险参数、执行交易、在 DeFi 协议和 CEX 之间重新平衡组合。

为何重要：这一预测将 Agent 经济的范畴从企业工具扩展到了个人财富管理，意味着 Agent 将深度介入万亿美元级别的金融市场。

安全与治理

8. MCP 协议安全漏洞：20万 AI Agent 服务器暴露

安全公司 OX Security 审计发现，Anthropic 创建的 Model Context Protocol（MCP）在 STDIO 实现中存在严重安全漏洞，导致约 20 万台 AI Agent 服务器暴露。MCP 由 Anthropic 于2024年末发布，随后 OpenAI 于2025年3月采用。

为何重要：随着 MCP 成为 AI Agent 与工具通信的事实标准，其安全漏洞的影响范围极广。企业需立即检查 Agent 服务器配置，并等待官方安全补丁。

📰 VentureBeat

为何重要：新加坡正在成为亚太地区 AI 监管的标杆，其 Agentic AI 框架很可能被其他司法管辖区参照。

行业趋势与数据

10. 斯坦福 AI Index 2026：12 项关键发现

斯坦福 HAI 发布年度 AI 指数报告，揭示以下关键趋势：

  • 投资激增：2025年全球企业 AI 投资达 5817 亿美元（同比+130%），美国以 2859 亿美元领跑，是第二名中国的 23 倍

  • AI 能力分化：AI Agent 在网络安全任务中解决率达 93%（2024年为 15%），但在多步科学推理中仅 40%（人类专家约 80%）

  • 劳动力冲击已至：AI 对就业的影响已从预测变为现实，年轻人群体首当其冲

为何重要：数据清晰地表明 AI 正在从"实验"走向"现实"，但能力分布极不均匀。
