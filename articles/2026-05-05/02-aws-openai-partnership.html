OpenAI 与 AWS 深化合作：GPT-5.5、Codex 登陆 Amazon Bedrock

 |  📅 2026年5月4日

原文链接: AWS News Blog | AWS Weekly Round-up

信源: Amazon Web Services (官方)

摘要

AWS 在 "What's Next with AWS 2026" 大会上宣布与 OpenAI 的合作伙伴关系进入新阶段，将 GPT-5.5、Codex（编码智能体）和 Bedrock Managed Agents 带入 AWS 环境。这是继 AWS CEO Matt Garman 与 OpenAI 领导层共同登台之后的重大合作扩展。

为什么重要

此前，OpenAI 的产品主要通过独立订阅或 Azure 云提供。此番登陆 AWS Bedrock 意味着：

  • AWS 企业客户可直接在现有 AWS 环境中使用 OpenAI 的前沿模型
  • 可使用 AWS 凭证进行身份认证
  • Codex 使用量可计入 AWS 云承诺

三大核心产品（Limited Preview）

  1. GPT-5.5 on Bedrock：OpenAI 最新旗舰模型，支持复杂推理和长任务
  2. Codex on Bedrock：AI 编码智能体，可通过 Bedrock API 访问，包含 Codex CLI、桌面应用和 VS Code 扩展
  3. Bedrock Managed Agents (Powered by OpenAI)：结合 OpenAI 前沿模型与 AWS 基础设施的托管智能体服务

Amazon Quick 也同期发布

AWS 同时推出 Amazon Quick——一款面向工作的 AI 助手，可连接日历、邮件、文件等企业应用，用自然语言完成任务。现在提供桌面应用预览版和 Free/Plus 订阅计划。

技术细节

Bedrock Managed Agents 基于 OpenAI 的 harness 构建，号称能"解锁前沿模型的全部潜力"，实现更快的执行、更清晰的推理和长任务的可靠控制。

行业影响

这一合作将 OpenAI 的产品线更深地嵌入企业云生态，与微软 Azure 的 OpenAI 合作形成直接竞争。对 AWS 企业客户而言，这意味着在不需要单独管理 OpenAI 账户的情况下，就能使用 OpenAI 最强大的工具。

与 IBM Think 的关联

IBM 和 AWS 同日发布重大 AI 产品，表明企业 AI 平台竞争正在进入白热化阶段——基础设施供应商纷纷将 AI 智能体能力作为核心差异化点。
