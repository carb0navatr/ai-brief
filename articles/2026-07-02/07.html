title: "Claude Sonnet 5 is here: mid-tier model with tool use and autonomous agents" source: Anthropic date: 2026-06-30 url: https://www.anthropic.com/news/claude-sonnet-5

为什么重要

Anthropic 推出 Claude Sonnet 5，定位中档模型但能力大幅增强，特别是对规划工具、浏览器和终端的原生支持，使其成为当前最具竞争力的 AI Agent 基础模型之一。值得关注的是，新版在危险网络安全任务上的能力被显著降低，反映出 Anthropic 在安全与能力之间做出了明确的权衡选择。

关键要点

  • 中档定位，高端性能：Claude Sonnet 5 定位介于 Haiku 和 Opus 之间，但在多项基准上接近 Opus 4.8 的表现。
  • 工具使用能力大幅提升：原生支持规划、使用浏览器和终端等工具，显著增强了作为 AI Agent 的可用性。
  • 自主 Agent 友好：更强的长程任务处理能力和工具调用稳定性，使其更适合构建自动化 Agent 工作流。
  • 安全能力再平衡：危险网络安全任务的能力被大幅削弱，体现了 Anthropic 在模型安全对齐上的主动选择。
  • 定价策略预期：中档定位通常意味着更有竞争力的价格，有望成为企业级 Agent 应用的主流选择。
