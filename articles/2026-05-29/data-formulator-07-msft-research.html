Data Formulator 0.7：微软开源企业数据分析工具

为什么重要

企业数据分析通常面临数据孤岛、专业知识门槛高、工作流难以复现等挑战。微软研究院发布的 Data Formulator 0.7 通过 AI Agent 连接多源企业数据、辅助数据分析与可视化迭代，并用多模态工作区替代"孤立的聊天交互"，让非技术背景的分析师也能完成复杂数据分析，同时保留完整可复现的工作流程。这对构建企业 AI 分析平台具有重要的参考价值。

关键要点

  • 多源数据统一接入：Data Connectors 功能支持跨数据库、数据仓库、BI 系统、对象存储和本地文件的持久连接，实现一次配置、重复使用，减少平台团队重复对接工作量。
  • 上下文感知 AI Agent：不同于单次 Prompt，Data Formulator 的 Agent 可访问完整分析工作区（已连接数据源、已加载表格、历史图表、用户目标），通过工具而非纯文本推理执行数据准备、分析建议和可视化生成。
  • 多模态分析工作区：Data Thread（结构化对话）保留每个问题、中间发现和图表的完整历史；Interactive Canvas 支持直接在画布上编辑可视化，两者在同一环境中互补协作。
  • 无需 SQL 或编程：用户通过自然语言与 Agent 交互，Agent 自动完成数据准备、转换、图表生成，并可回溯和比较历史分析步骤。
  • 完全开源：项目已在 GitHub 公开，演示站点的配套工具同步上线，teams 可基于此构建适用于自身数据基础设施的定制分析能力。
