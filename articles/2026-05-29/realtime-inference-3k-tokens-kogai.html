Kog AI 实现标准数据中心 GPU 实时 LLM 推理——3000 tokens/s

为什么重要

当前 AI 推理软件普遍存在严重的软件层面的效率瓶颈，使得标准数据中心 GPU 的真实解码速度远低于硬件理论上限。Kog AI 通过模型架构/推理引擎/底层 CUDA 内核的协同设计（co-design），在 8× AMD MI300X GPU 上实现了单请求 3000 tokens/s 的输出速度，在 8× NVIDIA H200 上达到 2100 tokens/s。这一速度已将 AI 推理推进到实时响应领域——生成 50,000 tokens 耗时从约 8 分钟降至 20 秒以内，直接改变了 AI Agent 产品的可行性边界。对于有大模型推理需求的 AI Labs、政府 AI 项目和企业用户而言，无需采购专用推理硬件即可获得极低延迟。

关键要点

  • 速度里程碑：8× AMD MI300X GPU：3000 tokens/s（单请求）；8× NVIDIA H200：2100 tokens/s（均无需推测解码 speculative decoding）。
  • 性能瓶颈核心在于内存带宽而非算力：现代 AI GPU 的峰值浮点运算能力（~400 FLOPs/byte）远高于内存带宽对应的实际能力（~1 FLOPs/byte），单请求自回归解码属于内存带宽受限任务，因此 GPU 节点有充足的潜力可挖。
  • 全栈协同优化是关键：现有推理软件栈在解码场景存在软件瓶颈，而非硬件限制。通过模型架构、运行时和底层 GPU 代码的协同设计作为统一延迟优化流水线，可在标准数据中心 GPU 上接近硬件理论解码速度上限。
  • Agent 场景受益最大：Agent 串行循环（检查-规划-编辑-测试-修订）中生成密集步骤（规划、代码编写、追踪分析）决定循环速率。更快的 token 生成直接将 Agent 工作流耗时从数分钟压缩到秒级，改变产品设计可能性。
  • 已开放技术预览：2B 编码模型在 Kog Playground 上开放测试，大型第三方 MoE 模型支持即将上线，企业可在标准 GPU 上部署并测试。
