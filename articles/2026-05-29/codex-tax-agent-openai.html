OpenAI 与戴尔合作：Codex 构建自我改进型 Tax AI Agent

为什么重要

OpenAI 与 Thrive Holdings 联合为 Crete 地区 30+ 会计事务所打造了 Tax AI 系统，展示了一种可量化的自我改进 Agent 构建路径。该系统通过生产追踪数据将从业者的修正反馈转化为结构化信号，Codex 以此为输入执行有上下文的工程改进，无需工程师逐一人工排查即可推动产品能力提升。这一案例将"自我改进 Agent"从概念落地为具体可复用的工程系统，对所有依赖专业领域知识的 AI 应用具有重要参考意义。

关键要点

  • 可量化的自我改进成果：上线三个月内，75% 正确字段完成率从 25% 提升至 86%；90% 和 100% 完成率上线后增速更快。从业者单笔报税准备时间节省约 1/3，准确率达 97%，效率提升 50%。
  • 三位一体改进循环：① 贴近从业者——从业者的直觉和判断决定改进优先级；② 生产全程留痕——Tax AI 追踪从源文件到终态申报的完整路径；③ Codex 驱动改进——生成有界工程任务，有明确成功条件和验证门控。
  • 从从业者修正到有界 Codex 任务的完整链路：修正差值 → 按字段分组失败模式 → 形成目标评估集 → Codex 调查根因 → 提出代码改动 → 运行目标及回归评估 → 生成候选 PR。
  • 可复用的抽象层：租赁物业（Schedule E）耗时约六周完成，后续扩展至 Schedule C 和 Schedule A 时已有可直接复用的评估规范、审查流程和实现模式。
  • 规模化前景：Thrive Holdings 将此框架推广至记账、审计、IT 运维等更多垂直领域，证明这一模式具有跨行业扩展潜力。
