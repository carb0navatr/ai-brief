Claude Opus 4.8 登顶 AI 模型排行榜

为什么重要

Anthropic 最新发布的 Claude Opus 4.8 以 61.4 分登顶 Artificial Analysis 智能指数，力压 GPT-5.5 xhigh（60.2 分），标志着 Anthropic 在知识工作 Agent 任务上重新夺回领先地位。此次提升并非依赖更多输出 tokens，而是在相同 token 数量下实现大幅性能跃升，效率极高。对于关注 AI 应用落地的从业者而言，这意味着 Claude Opus 4.8 在复杂知识工作场景中的实用价值已超越 GPT-5.5，是当前企业 AI 选型的重要参考节点。

关键要点

  • 智能指数登顶：Claude Opus 4.8 得分为 61.4，较 Opus 4.7 提升 4.1 分，以 1.2 分优势领先 GPT-5.5 xhigh（排名第二），重新夺回 Artificial Analysis 智能指数榜首位置。
  • 知识工作 Agent 任务大幅领先：在 GDPval-AA（Anthropic 与 Artificial Analysis 联合发布的知识工作 Agent 评估基准）上，Opus 4.8 得分 1890 Elo，相较 Opus 4.7 大幅提升 137 分，对 GPT-5.5 的胜率约为 67%。任务轮次减少 15%，输出 token 减少 35%。
  • 科学推理能力显著提升：在 Humanity's Last Exam（终极学术推理基准）中领先 OpenAI 和 Google，位居第一；在 CritPt 物理基准上也超越 Gemini 3.1 Pro。
  • 幻觉率保持最低：Opus 4.8 幻觉率约为 35.9%，显著低于 Google 和 OpenAI 的模型，延续了 Claude 系列一贯的低幻觉优势。
  • 多项基准稳健提升：Terminal-Bench Hard +6.8 分、τ²-Bench Telecom +5.9 分、IFBench +3.6 分。
  • 定价与上下文保持不变：上下文窗口维持 100 万 tokens，定价 $5/$25 每百万 tokens 输入/输出，与 Opus 4.7 一致。
