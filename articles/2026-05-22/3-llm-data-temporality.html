研究揭示：大语言模型预训练中的数据时序性影响

为什么重要： 这项研究首次系统性地揭示了预训练数据的顺序对 LLM 时间知识的影响。研究表明，按时间顺序组织的预训练数据可以让模型获得更"新鲜"的知识，而打乱顺序反而有利于掌握更"陈旧"的事实。这一发现对如何构建更准确、更具时效性的大语言模型具有重要指导意义。

关键要点：

  • 研究团队引入了包含 7000+ 道时间相关问题的综合基准测试，以及配套的时间知识评估协议
  • 在按时间顺序的 Common Crawl 快照上预训练 6B 参数模型，与标准打乱预训练进行对比
  • 按时间顺序预训练的模型在保持通用语言理解能力的同时，展现出更及时、更精确的时间知识
  • 打乱预训练的模型在处理较旧数据时表现更好，可能是因为事实重复率更高
  • 研究提供了代码、模型检查点和数据集，均发布于 GitHub 和 Hugging Face
