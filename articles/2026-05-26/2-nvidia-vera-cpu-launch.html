NVIDIA Vera CPU 正式出货：首款专为 AI Agent 打造的 CPU 登陆顶级 AI 实验室

为什么重要

NVIDIA 正式推出旗下首款独立 CPU——Vera，标志着 GPU 巨头完成了从 GPU 到 CPU 的全栈 AI 硬件布局。更关键的是，这是业界首款专为代理式 AI 工作负载设计的 CPU，而非沿用传统服务器 CPU 架构。对于 AI Agent 行业，这意味着推理过程中的"辅助计算"（代码生成、工具调用、状态管理）将获得定制化硬件加速，大幅提升 Agent 执行效率和吞吐量。

关键要点

  • Vera CPU 已于上周五通过 NVIDIA 副总裁 Ian Buck 亲自交付至 Anthropic、OpenAI、SpaceX AI，并随后交付 Oracle Cloud Infrastructure
  • Oracle 宣布计划在 2026 年部署数十万枚 Vera CPU，以支撑其云上 Agent 计算需求
  • Vera CPU 专为高强度的"生成式计算"设计：模型在推理时需要动态生成 Python 代码等中间逻辑，Vera 在这类任务上具备架构级优势
  • SpaceX AI 正在评估将 Vera 用于强化学习工作负载和基于 Agent 的训练仿真管道
  • 黄仁勋在 GTC San Jose 首次发布时曾表示，Vera 将成为 NVIDIA 的下一个价值数十亿美元的业务
  • Vera CPU 与 Rubin NVL72 系统协同，共同构成了 AI Factory 的全栈基础设施，支撑代理式 AI 和长上下文推理
