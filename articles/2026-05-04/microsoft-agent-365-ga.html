Microsoft Agent 365正式发布：扩展代理安全与治理能力

📰 Microsoft Security Blog  |  📅 2026-05-01

AI agents已经存在于您的环境中。它们出现在您期望的地方（如Microsoft Copilot、Microsoft Teams和Microsoft 365），随着技术发展甚至出现在更多地方（本地 autonomous personal AI assistant或连接到敏感数据的新型SaaS agent）。

问题不在于agent是否存在，而在于它们 proliferation速度快、跨越应用程序、端点和云端，通常在 accountable for risk的团队的可见性和控制范围之外运行。当agent可以调用工具、访问数据并与其他agent交互时，任何“有用”的工作流都可能在几秒钟内转变为数据 over sharing、tool misuse或 over-privileged actions。

这就是为什么end-to-end observability很重要：当agent数量不断变化时，您无法管理您看不到的东西，您也无法保护您不理解的东西。

Microsoft Agent 365概述

Microsoft Agent 365帮助您控制agent sprawl，作为 control plane来观察、govern和secure agents及其交互——包括使用Microsoft AI构建的agent和来自生态系统合作伙伴的agent。

从今天开始，Agent 365正式发布。同时，我们宣布了新的Agent 365功能和改进的预览，以帮助您在适当的控制下扩展agent adoption。

主要新功能

独立运行的agent的可见性、governance和安全性

Agent 365正在扩展，以 cover agents that operate with their own credentials and permissions。

Shadow AI的发现

使用Microsoft Defender和Microsoft Intune的功能来发现本地和云端agent，包括Shadow AI。

本地和云端hosted agents的可见性

使用Agent 365 registry sync（现为公开预览）与AWS Bedrock和Google Cloud连接，实现跨平台的可见性和governance。

生态系统合作伙伴agents

与Genspark、Zensai、Egnyte、Zendesk等预构建agents一起工作，这些agents已完全配置为可由Agent 365管理。

定价

Agent 365现已在Microsoft 365 E7或独立版本可用，价格为每位用户每月15美元。
