AMD GAIA 0.17.5：本地 AI Agent 开发门槛进一步降低

📰 Phoronix  |  📅 2026年5月2日

概述

AMD 于2026年5月2日发布了 GAIA（Generative AI Is Awesome）0.17.5，这是其面向 Windows 和 Linux 的开源软件，旨在通过 Lemonade SDK 让用户轻松在 AMD 硬件上构建本地 AI Agent。本次更新将默认模型更换为 Google Gemma 4 E4B，并引入多项新功能。

主要更新

默认模型更换：Gemma 4 E4B 替代 Qwen 3.5 35B

GAIA 0.17.5 用 Gemma 4 E4B（约45亿有效参数，128K 上下文窗口，Apache 2.0 许可）替换了之前的 Qwen 3.5 35B + Qwen 3-VL-4B 双模型组合。

AMD 团队在发布说明中解释道：

"Gemma 4 E4B 原生多模态（约45亿有效参数，128K 上下文窗口，Apache 2.0 许可），一个模型覆盖了此前需要加载两个模型才能完成的任务。切换后的评测基线在14/15个捆绑场景中优于切换前的 Qwen 基线（13/15）。"

关键优势：

  • 单一模型覆盖 LLM 和 VLM 双重角色，减少系统资源占用
  • Apache 2.0 许可使企业本地部署更加灵活
  • 128K 上下文窗口适合复杂的长程 Agent 任务

新功能：Chat Lite

新增轻量级内置 Agent "Chat Lite"（chat-lite），面向资源受限的系统，降低了运行完整 Agent 的硬件门槛。

代码语义搜索：CodeAgent

增加通过语义而非精确关键词搜索代码的能力，提升 Agent 在编程任务中的效率。

UI 改进

GAIA 0.17.5 现在将 Agent UI 集成到 PyPI 包中，一行命令即可安装并启动：

pip install amd-gaia[ui] && gaia chat --ui

已知问题

测试中仍有一些问题值得关注：

  • Radeon 890M GPU 正常工作，但 Ryzen AI NPU 仍未被激活，即使在搭载 AMDXDNA 支持内核的 Ubuntu 26.04 上，NPU 使用率始终为 0%
  • 部分默认 Agent 在测试中出现错误

为何重要

本地 AI Agent 的工具链正在快速成熟。GAIA 0.17.5 的进展表明：

  1. 单模型多模态方案正在成为主流，降低了系统复杂度
  2. 本地 AI Agent 的安装和使用门槛在持续下降
  3. AMD 正在加大对 NPU（神经网络处理单元）的软件支持，但仍有优化空间

对于希望在本地硬件上运行 AI Agent 而不依赖云端 API 的开发者来说，GAIA 提供了越来越完整的一站式解决方案。
