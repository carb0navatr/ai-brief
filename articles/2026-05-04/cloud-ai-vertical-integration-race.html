云厂商 AI 垂直整合竞赛：AWS 补齐应用层短板

📰 Constellation Research  |  📅 2026年5月

发生了什么

三大云厂商（Google Cloud、Microsoft、AWS）正在加速 AI 垂直整合，构建从芯片到应用的完整 AI 栈。Constellation Research 的分析揭示了各家的战略定位和竞争态势。

Google Cloud 从一开始就是 AI/ML 公司。Google 从芯片（TPUs）到模型（Gemini）到数据平台（BigQuery）再到应用（Workspace）构建了完整的 AI 栈。Google Cloud 通过 Workspace 在业务应用和生产力层建立了良好基础。Gemini Enterprise Agent Platform 有望成为工作流编排器。Google Cloud 缺乏后端应用（ERP/CRM），但正日益成为多云环境中的 AI 引擎。

Microsoft 战略核心是在整个企业工作界面中整合 AI。Microsoft 现有的企业覆盖无与伦比——M365、Copilot、GitHub、Teams、Power Platform 和 Dynamics。Azure Foundry、SQL Server/Azure SQL、OneLake 和 WorkIQ 是额外优势。Microsoft 想成为"企业工作操作系统"，Azure 则是 AI 基础设施层。Microsoft 正在通过 Maia（推理）和 Cobalt（通用）芯片进入自定义硅领域。

AWS 长期主导基础设施即服务层，但应用层相对薄弱。Amazon Connect 家族（客户 AI、人才、决策、健康应用）的发布补齐了这一短板，与 Anthropic 的 Claude Cowork 形成对标。AWS 的优势在于没有历史包袱，可以更灵活地构建 AI 原生应用。

为什么重要

AI 基础设施竞争已从"算力"升级为"全栈能力"竞争。各家的战略差异：

维度 Google Microsoft AWS
核心叙事 AI 原生，从一开始就是 企业工作操作系统 按需消费的 AI 基础设施
芯片 TPUs Maia + Cobalt Nitro
模型 Gemini GPT + 自研 Titan
数据平台 BigQuery OneLake + SQL Redshift
应用层 Workspace M365 + Dynamics Connect
Agent 平台 Gemini Enterprise Agent 365 Bedrock Agents
开放策略 A2A + MCP MCP 合作 相对封闭

关键趋势

1. Agent 平台成为新的竞争焦点 Google 的 Gemini Enterprise Agent Platform、Microsoft 的 Agent 365、AWS 的 Bedrock Agents ——三大云厂商都在抢占企业 Agent 入口。

2. 应用层整合加速 Microsoft 的 M365 深度整合、AWS 的 Connect 家族扩展、Google 的 Workspace Studio ——应用层正在成为差异化关键。

3. 芯片自研成标配 Google 有 TPUs，Microsoft 有 Maia，AWS 有 Nitro。芯片成为控制成本和性能的关键。

企业采购建议

  1. 评估与现有系统的集成深度：M365 用户选 Microsoft，Google Workspace 用户选 Google
  2. 考虑多云策略：避免供应商锁定
  3. 关注协议开放性：A2A 和 MCP 的开放性将影响 Agent 生态的可扩展性
  4. 评估治理能力：Shadow AI 管控和安全治理将成为重要考量
