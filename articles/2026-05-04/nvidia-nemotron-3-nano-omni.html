NVIDIA Nemotron 3 Nano Omni：融合视觉、音频和语言的开源多模态 Agent 模型

📰 NVIDIA Blog  |  📅 2026 年 4 月 28 日

摘要

NVIDIA 正式发布 Nemotron 3 Nano Omni，一款开源多模态模型，将视觉、音频和语言能力统一在单一系统中。与传统 Agent 需要串联多个单模态模型的方案相比，效率提升高达 9 倍，并在文档智能、视频理解和音频理解六大基准测试中排名第一。

核心内容

痛点：分离式多模型架构的代价

当前 AI Agent 系统通常需要三种独立模型分别处理不同模态：

  1. 视觉模型 → 处理图像和视频帧
  2. 语音/音频模型 → 处理音频输入输出
  3. 语言模型 → 处理文本理解和生成

每次跨模态数据传递都会：

  • 损失上下文：信息在不同模型间传递时不可避免地丢失细节
  • 增加延迟：每个模型都有独立的推理时间，叠加后用户等待感显著
  • 提升成本：多个模型 = 多倍算力消耗
  • 增加工程复杂度：需要维护多个模型版本、API 接口和状态同步

Nemotron 3 Nano Omni 的解决思路

Nemotron 3 Nano Omni 的核心创新是单一统一的多模态架构，同时支持：

  • 文档理解（PDF、图表、结构化数据）
  • 视频帧理解与分析
  • 音频语音理解

这意味着 Agent 可以在单次推理循环中处理来自文本、图像、音频的所有输入，无需跨模型传递数据。

技术亮点

  • 六项基准测试排名第一：覆盖文档智能、视频理解、音频理解等核心能力
  • 部署灵活性：从 NVIDIA Jetson 嵌入式设备到 DGX Spark/DGX Station 工作站，再到数据中心和云端，同一模型全场景覆盖
  • 开源：模型权重和技术文档完全开放，企业可自主部署
  • 效率提升 9 倍：相比分离式多模型方案，端到端推理成本和延迟大幅降低

已采用企业

Aible、Applied Scientific Intelligence (ASI)、Eka Care 等公司已率先集成该模型。Eka Care 正在利用该模型构建印度大规模患者护理的多模态医疗 Agent 系统。

对 Agent 开发者的意义

对于正在构建生产级 AI Agent 的团队而言，Nemotron 3 Nano Omni 提供了一条无需拼接多个专有模型的生产路径：

  • 工程简化：一套 API，一套权重，一套推理管道
  • 成本可控：单一模型推理成本远低于多模型组合
  • 延迟降低：单次推理替代多次跨模型调用
  • 全栈可控：开源意味着企业可以完全掌控自己的 Agent 基础设施

NVIDIA 同时发布了配套的技术教程、合集和部署指南，开发者可通过 NVIDIA 开发者社区获取。
