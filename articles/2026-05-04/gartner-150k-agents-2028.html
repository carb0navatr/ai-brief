Gartner 预测 2028 年企业将部署 15 万个 AI Agent

📰 Computerworld  |  📅 2026年4月30日

发生了什么

Gartner 在本周发布的一项调查预测，到 2028 年，Fortune 500 企业将平均部署约 150,000 个 AI Agent。这一数字与 2025 年平均约 15 个 Agent 的现状形成了天壤之别。

Gartner 高级总监分析师 Max Goss 表示，业界对 Agent AI 能力的认知已发生根本性转变。AI Agent 不再是简单的"问答框"，而是能够接受实际工作委托的数字同事。

目前，许多 AI Agent 已经能够处理文档摘要等基础任务。下一波 Agent 将能够自动处理电子表格和 Word 文档、自动化工作流程，并提供更友好的用户界面。Google Workspace 和 Microsoft 365 已经率先将 Agent 能力嵌入日常工作流程。

Gartner 提出的 Agent 管理六步框架包括：

  1. 建立统一的 Agent 清单
  2. 定义用例和价值指标
  3. 建立安全与合规政策
  4. 实施监控和审计机制
  5. 优化 Agent 性能和成本
  6. 建立 Agent 生命周期管理流程

为什么重要

规模跳跃而非线性增长：从 15 个到 150,000 个是 10,000 倍的增长，而非 10 倍。这种爆炸性扩张将给企业的 IT 架构、安全治理和成本管理带来根本性挑战。

Shadow AI 的放大效应：Gartner 指出的"Shadow AI"问题与 Microsoft Agent 365 的发布形成呼应。当 Agent 数量呈指数增长时，未经 IT 部门知晓和批准的 Agent 将在企业内外快速蔓延，带来数据泄露和合规风险。

人机协作模式重构：从"人类提问、AI 回答"到"AI 自主执行、人类监督"是工作方式的根本转变。这种转变要求企业重新设计工作流程、培训员工并建立新的问责机制。

关键数据

指标 2025年 2028年预测
Fortune 500 企业平均 Agent 数量 ~15 ~150,000
Agent 功能渗透率 早期采用 主流采用
Shadow AI 风险等级 中 高

行业影响

Gartner 的预测为 AI Agent 产业设定了明确的目标线。对基础设施供应商而言，这意味着需要准备好支撑前所未有的 Agent 并发量；对安全供应商而言，Agent 治理将成为新的战场；对企业 IT 而言，管理 Agent 生命周期将成为与管理系统同等重要的能力。

Agent Sprawl（Agent 蔓延）已成为 Gartner 定义的新兴风险类别，企业需要在 Agent 规模扩张之前建立治理框架。
