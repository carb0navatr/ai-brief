MoonPay 推出 MoonAgents Card：AI Agent 的加密支付万事达卡

📰 Startup Fortune  |  📅 2026年5月1日

概述

MoonPay 于2026年5月1日正式推出 MoonAgents Card，这是一张虚拟万事达借记卡，允许用户和授权的 AI Agent 直接从链上稳定币余额消费，适用范围覆盖所有接受万事达的在线商户。

该产品由 MoonPay 与 Exodus（加密钱包）和 Monavate（支付技术提供商）合作开发，通过 MoonAgents CLI 和 MoonAgents 工作流进行管理，专为程序化消费场景设计，而非普通消费者结账流程。

核心功能

1. Agent 可编程消费

AI Agent 现在可以在无需人类介入的情况下，代表用户完成以下操作：

  • 订阅服务续费（如 SaaS 产品、AI API 费用）
  • Agent 购买随业务扩展而增长的资源（如云算力采购）
  • 差旅或物流预订（作为业务流程的一部分自动完成）
  • 随时按需配置云端计算资源

2. 消费控制与合规

传统信用卡依赖持卡人自身的判断作为欺诈和滥用过滤器。Agent 信用卡需要不同的模型——开发者或授权用户可以编程设置：

  • Agent 可消费的金额上限
  • 允许的商户类别
  • 消费频率限制
  • 单笔交易上限

MoonPay 的 CLI 和 MoonAgents 工作流将这些控制机制集成到 Agent 的运行环境层面，而非事后补救。

3. 金融网络支持

万事达卡作为该产品的网络支持方，释放了明确的信号：主流支付网络不打算抵制 Agent 经济，而是在积极参与。这一网络级别的开放态度消除了可能阻碍 Agent 商业发展的一个监管和基础设施障碍。

为何重要

AI Agent 的支付基础设施一直是待解决的问题。AI Agent 已经能够浏览网页、撰写内容、推理分析和执行工作流，但一旦需要代表用户实际消费，基础设施一直缺位。MoonPay 正在直接填补这一空白。

MoonAgents Card 被定位为消除这一瓶颈的支付层。对于真正将 Agent 纳入生产系统的企业来说，这是关键的基础设施补充——而万事达卡的参与证明了传统金融体系对 Agent 经济的开放态度。

行业背景

Visa 和万事达卡一直在密切关注 Agent 支付领域。MoonAgents Card 的发布表明，主流金融网络对 Agent 经济的参与已经从观察阶段进入实际产品阶段。这与 Kite AI 的 Agent Passport、Experian 的 Agent Trust 等同期发布的支付和身份工具一起，共同构成了 Agent 经济基础设施的雏形。
