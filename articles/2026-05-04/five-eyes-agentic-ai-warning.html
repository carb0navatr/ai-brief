五眼联盟联合警告：Agentic AI 风险过高，不宜快速部署

📰 The Register  |  📅 2026年5月4日

发生了什么

美国网络安全与基础设施安全局（CISA）与五眼联盟其他成员国（英国、加拿大、澳大利亚、新西兰）于 5 月 2 日联合发布了一份名为《谨慎采用 Agentic AI 服务》的指南，对 Agentic AI 技术发出前所未有的安全警告。

指南的核心论点是：Agentic AI 系统很可能表现异常，且会放大组织现有安全弱点。随着 Agentic AI 系统在关键基础设施和国防领域广泛部署，"为防御者实施安全控制以保护国家安全和关键基础设施"变得至关重要。

指南详细阐述了 Agentic AI 的攻击面问题：实现 Agentic AI 需要使用多个组件、工具和外部数据源，这创造了一个"互联互通的攻击面"，恶意行为者可以利用。"因此，Agentic AI 系统中的每个组件都会扩大攻击面，使系统暴露于额外的利用途径。"

核心建议

最小权限原则：Agent 应仅获得完成其任务所需的最小权限，避免权限蔓延。

持续审计：建立实时监控机制，追踪 Agent 的行为模式和系统访问。

阶段性部署：从明确界定的低风险任务开始，逐步扩展 Agent 的应用范围。

假设异常行为：在安全实践、评估方法和标准成熟之前，组织应假设 Agentic AI 系统可能表现异常，并据此规划部署。

韧性优先于效率：优先考虑韧性、可逆性和风险控制，而非效率提升。

为什么重要

五眼联盟的联合声明代表了主要英语国家情报机构对 Agentic AI 的统一立场。这种级别的国际协调警告非常罕见，表明各国政府对 Agentic AI 的安全风险已达到高度共识。

Agent 安全的独特挑战：传统安全工具（如 MITRE ATLAS 和 OWASP）主要针对 LLM，对 Agent 特有攻击向量（如工具滥用、权限提升、多步攻击链）的覆盖不足。这意味着现有的安全评估框架存在重大空白。

监管先行：CISA 的指南可能成为其他司法管辖区的参照标准。企业在部署 Agent 时应将此视为"预合规"要求，提前建立相应的治理框架。

安全团队的关键行动项

  1. 盘点现有 Agent 的权限和数据访问范围
  2. 建立 Agent 行为的实时监控机制
  3. 对高风险工作流实施人类审批环节
  4. 将 Agent 安全纳入威胁模型和渗透测试范围
  5. 跟踪 MITRE ATLAS 和 OWASP 的 Agent 安全更新

行业反应

安全专家普遍认同指南的方向。Tuskira CEO Piyush Sharma 表示："企业不能简单地将 Agent 丢进生产环境，然后祈祷护栏能撑住。他们需要理解每个 Agent 能访问什么、如何行为、哪些系统信任其输出，以及如果 Agent 被操纵哪些攻击路径会变得可达。"

Swimlane 安全自动化架构师 Nick Tausek 强调："安全团队需要对 Agent 行为、接触的系统以及行为偏离预期模式的时间保持持续可见性。在 Agent 行为越过红线时，将人类审批纳入高风险工作流并自动化遏制至关重要。"
