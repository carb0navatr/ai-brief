Mistral AI在Vibe中推出Remote Agents和Mistral Medium 3.5，SWEBench验证得分77.6%

📰 MarkTechPost  |  📅 2026-05-02

Mistral AI一直在quietly building一个相当实用的coding agent ecosystem in the open-source/weights AI space，而现在他们正在交付其最重要的 infrastructure upgrade。

Mistral团队宣布在Vibe（其coding agent platform）中推出remote agents，同时还推出了Mistral Medium 3.5的公开预览——一个128B dense模型，现在作为Vibe和Le Chat中的默认模型。

什么是Vibe，为什么它很重要？

Mistral Vibe是一个通过CLI（command-line interface）访问的coding agent，让AI模型代表您处理软件任务——编写代码、重构模块、生成测试、调查CI failures等。可以把它想象成一个永不疲倦的初级开发人员。

到目前为止，Vibe sessions一直在本地运行，这意味着agent与您的笔记本电脑和terminal绑定。现在，这一切都变了。

Remote Agents：agent运行时您可以离开

现在coding sessions可以在您不在时处理long tasks。许多可以parallel运行，您不再成为agent每个步骤的bottleneck。

这是关键的行为转变。您启动一个任务，让cloud处理剩下的事情。您可以检查agent正在做什么，包括file diffs、tool calls、progress states和surfaced questions。

每个session在isolated sandbox中运行。当工作完成时，agent可以在GitHub上打开pull request并通知您，这样您只需review结果，而不需要查看producing it的每个keystroke。

Mistral Medium 3.5：支撑这一切的模型

这个新发布的模型是Mistral Medium 3.5——Mistral团队描述为其首款flagship merged model。

这是一个具有256k context window的128B dense模型，处理instruction-following、reasoning和coding in a single set of weights。

该模型也是多模态的。Mistral从头开始训练vision encoder以处理variable image sizes和aspect ratios——这是一个 notable architectural choice。

Mistral Medium 3.5在SWEBench验证中得分77.6%，领先于Devstral 2和Qwen3.5 397B A17B等模型。

Le Chat中的Work模式

Mistral还推出了Le Chat中的Work模式——一种新的agentic mode，用于更general、multi-step任务。在Work模式下，connectors默认开启，agent可以reach into documents、mailboxes、calendars和其他系统，获取rich context来take correct action。
