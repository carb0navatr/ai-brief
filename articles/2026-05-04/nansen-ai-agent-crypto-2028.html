Nansen 预测：2028 年 AI Agent 将主导加密投资

📰 Bitcoin News  |  📅 2026年5月3日

概述

区块链分析领域的头部平台 Nansen 预测，到2028年，AI Agent 将成为大多数人投资加密货币的默认方式。届时，投资者不再是手动选币或阅读K线图，而是让自主运行的 AI Agent 代为执行所有投资决策。

核心预测

Nansen 描绘的 Agent 主导加密投资场景：

每个 Agent 可以：

  • 7×24 小时监控市场状况
  • 管理风险参数
  • 自动执行交易
  • 在 DeFi 协议和中心化交易所之间重新平衡组合
  • 同时与多个 DeFi 协议、CEX 和链上头寸交互

规模预测：数十亿个 Agent 同时运行，每个代表一个个人投资者、机构或协议，在预设的自动化决策框架内运作。

类比软件开发工程化

Nansen 将这一转变与软件工程领域的重大范式转变进行类比：

就在十年前，大多数开发团队仍然通过大量手动流程编写和部署代码。今天，CI/CD 管道、自动化测试和部署流水线已经自主处理了大部分工作。

Nansen 认为，资产管理正在经历同样的结构性转变——而且时间线被大幅压缩，完全由大语言模型和链上自动化工具的快速进步驱动。

与传统交易机器人的本质区别

自动交易机器人在加密领域早已存在。但 Nansen 描述的 Agent 范式与它们有本质区别：

  • 传统机器人：基于简单规则的程序（价格达到某阈值即触发买卖）
  • Agent：目标导向系统，能够跨多个数据输入进行推理，执行复杂多步策略

这意味着 Agent 可以做出现有机器人无法做到的决策，比如根据宏观事件、链上数据、社交媒体情绪等多维度信息做出综合判断。

对加密市场的影响

如果 Nansen 的时间线准确，加密市场结构将面临深刻变化：

  1. 流动性动态重塑：Agent 驱动的大规模投资将改变流动性分布
  2. 交易微观结构改变：CEX 和 DeFi 协议都需要构建能处理高频自主活动的设施
  3. 市场监控挑战：交易所和 DeFi 协议需要新的风控手段应对 Agent 主导的市场

为何重要

Nansen 预测的影响力在于：作为加密领域最受引用的分析平台之一，其公开表态为一个具体的时间线（2028年）提供了可信度。这不只是一个初创公司的愿景，而是行业头部数据平台的正式预测。

无论2028年这一具体日期是否准确，Agent 经济向个人财富管理领域的渗透趋势已经清晰可见。
