Google Cloud Next 2026：Gemini Enterprise Agent Platform 全栈出击

📰 The Next Web  |  📅 2026年5月

发生了什么

Google 在 5 月 Cloud Next 2026 大会上发布了全面的企业 AI Agent 产品矩阵，核心是 Vertex AI 更名为 Gemini Enterprise Agent Platform，以及一系列配套产品。

主要发布：

1. Gemini Enterprise Agent Platform 统一的企业 AI 入口，整合之前的 Vertex AI、Agentspace 等产品，提供从开发到治理的全套工具。

2. Workspace Studio 无代码 Agent 构建工具，允许非技术人员在 Google Workspace 环境中创建定制化 Agent。计划于 2026 Q2 上线。

3. Project Mariner Google DeepMind 的网页浏览 Agent，基于 Gemini 2.0，WebVoyager 基准得分 83.5%。支持在云端虚拟机上同时处理 10 个任务。可自动完成购物、信息检索和表单填写。目前仅向美国 Google AI Ultra 订阅者开放。

4. Agent2Agent (A2A) 协议 Google 主导的跨平台 Agent 通信协议，已在 150 家企业生产环境运行（而非试点），包括 Microsoft、AWS、Salesforce、SAP 和 ServiceNow。该协议由 Linux 基金会 Agentic AI Foundation 管理，已升至 v1.2 版本，使用加密签名验证 Agent 身份。

5. Managed MCP Servers 通过 Apigee 提供托管 MCP 服务器，实现 API 到 Agent 的桥接，帮助企业将现有 API 资产快速接入 Agent 生态。

6. Model Garden 扩展 200+ 模型，包括 Anthropic Claude 等第三方模型。

为什么重要

Google 的核心叙事是"全栈，从芯片到收件箱"——TPUs + Gemini + BigQuery + Workspace 的垂直整合。这直接对抗 AWS 和 Microsoft 的类似战略。

A2A 与 MCP 的互补定位：A2A 处理 Agent 之间的通信，MCP 处理 Agent 与工具/数据源的连接。Google 选择同时推进两者，形成完整的协议层。

Workspace Studio 的无代码策略：让非技术用户也能构建 Agent，这将大幅扩展 Agent 的使用范围——从开发者到业务人员。

150 家企业的生产级部署：A2A 已不再是实验性协议，而是进入企业生产的关键基础设施。

行业影响

Google 的这一系列发布标志着企业 AI Agent 平台竞争进入白热化阶段。Microsoft 有 Agent 365，Google 有 Gemini Enterprise Agent Platform，两者的正面竞争将推动功能快速迭代和企业采用加速。

值得注意的是，Google 强调 A2A 协议的开放性——与 Anthropic 的 MCP 互补——这与 Microsoft 的策略不同。Google 希望成为"Agent 互联网"的枢纽，而非封闭生态。
