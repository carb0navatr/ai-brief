DeepSeek-V4 发布：价格比 OpenAI 低 97%，开源 Agent 能力比肩顶级闭源模型

📰 观察者网  |  📅 2026年4月26-28日

发生了什么

深度求索于 2026年4月26日发布 DeepSeek-V4 预览版并同步开源，随即大幅降低产品价格：

价格对比

模型 DeepSeek V4-Flash DeepSeek V4-Pro GPT-5.5 (OpenAI)
缓存命中价格 0.02元/百万 Tokens 0.1元/百万 Tokens ~3.4元/百万 Tokens
原价 0.2元 1元 —
降幅 90% 90% —

限时 2.5 折优惠后，V4-Pro 实际价格仅 0.025元/百万 Tokens，比 GPT-5.5 便宜 97%，单次对话成本差距可达 32倍。

能力表现

DeepSeek V4-Pro 在多项评测中表现亮眼：

  • Agentic Coding：达当前开源最佳水平，优于 Claude Sonnet 4.5，交付质量接近 Claude Opus 4.6 非思考模式
  • 世界知识：仅次于 Gemini-3.1-Pro，大幅领先其他开源模型
  • 数学/代码：超越所有已公开开源模型，比肩世界顶级闭源模型
  • Web 开发任务（Arena.ai）：与 GPT-5.4-high、Gemini-3.1-Pro 持平

市场影响

OpenRouter 平台数据显示，DeepSeek-V4 上线后：

  • 4月25日单日调用量达 136亿 Tokens，较前一日增长近 4倍

上海财经大学特聘教授胡延平分析认为，DeepSeek 的降价举措旨在吸引更多用户，特别是企业用户、开发者和 Agent 用户。

技术整合

DeepSeek 定价调整是技术升级以及与华为昇腾生态深入整合的一部分：

  • V4 能够以更低成本支持更复杂的基于 Agent 的应用
  • 与昇腾超节点的整合可能进一步增强成本竞争力
  • 支持更广泛的应用普及

行业意义

DeepSeek V4 的出现正在重塑大模型定价格局。AI 模型分析平台 Artificial Analysis 指出，尽管 DeepSeek V4 与顶尖闭源模型仍有差距，但成本效益更高：

  • DeepSeek V4-Flash 完成智能指数测试的成本约 113美元
  • Claude Opus 4.7 模型的成本约 4,811美元
