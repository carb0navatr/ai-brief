Microsoft Agent 365 正式发布：Shadow AI 成为企业安全新战场

📰 Microsoft Security Blog  |  📅 2026年5月1日

发生了什么

Microsoft 于 5 月 1 日正式发布 Agent 365 通用版本，并推出 Shadow AI 发现与管控功能。这标志着企业 AI Agent 治理进入实质性阶段。

核心问题：AI Agent 正在快速扩散——它们出现在你预期的位置（Microsoft Copilot、Teams、M365），也出现在你意想不到的地方（本地个人 AI 助手、连接到敏感数据的 SaaS Agent）。问题是这些 Agent 扩散速度极快、跨越应用、端点和云，且往往在负责风险管控的团队视野之外。当一个 Agent 能够调用工具、访问数据并与其他 Agent 交互时，任何"有用"的工作流都可能在几秒内变成数据过度分享、工具滥用或权限过度执行。

Agent 365 新功能：

1. Shadow AI 发现 扫描企业环境中的未受管理 AI Agent，包括本地运行在 Windows 设备上的 Agent（从 OpenClaw 开始，未来扩展到 GitHub Copilot CLI 和 Claude Code）。

2. Intune 策略控制 通过 Microsoft Intune 策略持续检测受管设备上的 Agent 使用情况，在 Microsoft 365 管理中心和 Intune 管理中心的新"Shadow AI"页面查看发现结果，并可阻止未受管理的 Agent 运行。

3. Agent 注册表 统一的 Agent 清单，Inventory 数据同步到 Defender 和 Intune，让 IT、端点管理和安全团队获得一致的 Agent 可见性。

4. 跨平台发现能力 同时覆盖云端和本地环境中的 Agent，这是现有云平台治理工具难以做到的。

为什么重要

Shadow AI 的危险性被低估：当一个没有经过 IT 审批的 Agent 获得企业数据访问权限时，它可能：

  • 意外泄露敏感数据到外部服务
  • 在未经授权的情况下调用昂贵 API，产生意外成本
  • 与其他未受管 Agent 共享数据，扩大攻击面
  • 执行超出预期的操作（如修改、删除数据）

治理的紧迫性：Gartner 预测 2028 年企业将部署 150,000 个 Agent。如果不从现在开始建立治理框架，届时将面临无法管理的混乱。

Microsoft 的先发优势：作为企业协作和设备管理的领导者，Microsoft 在 Agent 发现和治理方面具有天然优势。其 Defender 和 Intune 的深度集成使 Agent 治理成为可能，而这正是其他安全供应商难以匹敌的。

技术架构

Agent 365 的 Shadow AI 发现功能通过以下方式工作：

  1. 端点检测：Intune 持续监控 Windows 设备上运行的 Agent 进程
  2. 行为分析：识别 Agent 的数据访问和工具调用模式
  3. 风险评分：根据 Agent 的权限、数据访问范围和行为异常评估风险
  4. 策略执行：阻止高风险 Agent 运行或强制实施额外控制

企业行动建议

  1. 立即启用 Shadow AI 发现：了解企业内已有哪些 Agent 在运行
  2. 制定 Agent 接入政策：明确哪些 Agent 可以接入企业系统
  3. 建立权限最小化原则：Agent 应仅获得完成任务所需的最小权限
  4. 监控 Agent 行为：持续追踪 Agent 的数据访问和工具使用
  5. 准备 Agent 治理培训：让员工了解合规使用 AI Agent 的要求
