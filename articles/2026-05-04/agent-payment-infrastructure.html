Agent 商业支付基础设施快速成型：MoonPay、Kite、Experian 三路并进

📰 Digital Transactions  |  📅 2026年5月2日

概述

2026年5月初，AI Agent 的商业与支付基础设施迎来密集发布期。Experian（消费者与 Agent 身份验证）、Kite AI（Agent 身份与支付工具包）和 MoonPay（加密支付卡）相继推出新产品，共同构建 Agent 经济的基础设施层。

三家公司的定位

Experian Agent Trust：信任层

Experian 是全球领先的信用报告机构，其 Agent Trust 服务专注于解决 Agent 商业中的身份和信任问题：

  • Know Your Agent（KYA）框架：确保 Agent 发起的每笔交易背后都有经过验证的消费者身份
  • 实时信任令牌：结合身份验证和交易风险评估
  • 目标：让"Agentic Commerce"（Agent 商业）能够规模化——"没有信任，Agent 商业无法规模化"

Kite Agent Passport：钱包与身份

Kite AI 的 Agent Passport 为 AI Agent 提供：

  • 可编程安全钱包：Agent 可持有资金并代表用户消费
  • 用户主权控制：消费限额和授权购买目标由用户设定
  • Agent Interface & Experience：包含 Agent 注册、Harness（连接器）和服务发现功能
  • 测试集成：正在与 PayPal 和 Shopify 进行集成测试

MoonAgents Card：支付层

MoonAgents Card（见另一篇文章）提供加密货币到法币通道的 Agent 可编程消费卡，是 Agent 支付从链上到线下商户的桥梁。

为何重要

这三款产品代表了 Agent 经济基础设施的三个关键层次：

层次 产品 作用
信任层 Experian Agent Trust 验证"谁在控制这个 Agent"
身份层 Kite Agent Passport Agent 的身份证明和钱包
支付层 MoonAgents Card Agent 的消费通道

缺少任何一层，Agent 商业都无法真正规模化。目前这三层的同步发展，标志着 Agent 经济正在从概念走向现实。

万事达卡和 Visa 对这些产品的支持，进一步证明了主流金融网络对 Agent 经济的积极参与态度。
