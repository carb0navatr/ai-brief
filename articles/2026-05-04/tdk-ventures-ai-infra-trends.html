TDK Ventures：推理芯片和实体 AI 是下一个投资方向

📰 TechCrunch  |  📅 2026年5月4日

发生了什么

TDK Ventures 联合创始人 Nicolas Sauvage 在 StrictlyVC 旧金山活动上分享了他的投资逻辑。TDK 是日本电子巨头 TDK 的企业风险投资部门，管理 5 亿美元资产，已投资包括 Groq（估值 69 亿美元）在内的多个 AI 基础设施项目。

核心观点：

1. 推理芯片是下一个价值高地 Sauvage 在 2020 年（远早于生成式 AI 热潮）就投资了 Groq。当时 Groq 专注于推理——每次模型响应查询时的计算重活——而非训练。这种专注现在看来极具前瞻性，因为随着 Agent 系统的普及，推理需求将呈指数增长。

2. 芯片架构演进 Sauvage 观察到 AI 芯片正在整合更多 CPU 功能。这意味着芯片设计逻辑正在从"专业加速器"向"通用处理器+AI 加速"演进。

3. 实体 AI 的"灵巧性"瓶颈 模型能力正在快速提升，实体 AI（Physical AI）看起来不可避免，但还缺少"物理流畅性"。谁能把物理原型迭代速度提升到与代码迭代相同的水平，谁就拥有制造优势。

4. 中国的"氛围制造"威胁 Eclipse 的一份报告显示，中国制造商正在以 AI 辅助方式压缩物理产品的设计-构建-测试周期。这种能力与"氛围编码"（vibe coding）对软件的影响类似，但作用于硬件。西方供应链尚未准备好应对这种速度。

为什么重要

从软件 Agent 到基础设施：VC 视角下的 AI Agent 投资正在从"软件 Agent"向"推理基础设施"和"实体 AI"延伸。这意味着 Agent 产业链上游的芯片和物理系统将成为下一波投资热点。

推理成本的优化需求：随着 Agent 系统处理越来越多的任务，推理成本将成为企业的主要支出。优化推理效率（速度、成本、能耗）的解决方案将获得市场青睐。

Physical AI 的投资缺口：当前 AI 投资高度集中于软件层（模型、应用）。但在机器人、自动化制造等领域，真正的瓶颈是"灵巧性"——机械系统与 AI 决策的整合。这将是一个价值数百亿美元的投资机会。

  2. Physical AI：结合 AI 决策和物理操作的系统
  3. Agent 安全和治理：快速增长的蓝海市场
  4. 多 Agent 编排：协调多个 Agent 协作的基础设施
