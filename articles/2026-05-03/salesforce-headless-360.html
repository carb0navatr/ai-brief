Salesforce Headless 360：从"点击操作"到"API优先"的25年最大转变

📰 Salesforce官方博客  |  📅 2026年4月15日

事件概述

Salesforce于2026年4月15日正式发布 Headless 360，这是该公司25年历史上最重要的一次平台战略重组。核心转变是：将Salesforce的整个平台从"人类操作界面"转变为"AI Agent的基础设施"。这不是一个功能升级，而是一次彻底的架构重新定位。

为什么是现在？

Salesforce联合创始人Parker Harris的发问揭示了背景：

"为什么你还需要登录Salesforce？"

过去25年，使用Salesforce意味着在浏览器中点击控制台、手动更新案例、手动推进工作流。这是一个"人操作平台"的范式。

但在Agent时代，AI Agent也在"操作平台"，而它们不使用浏览器。它们调用API，调用MCP工具，运行CLI命令。如果平台需要人类点击界面才能工作，那它就还没有为Agent时代做好准备。

这一判断促成了两年前开始的内部转型，现在以Headless 360的形式正式发布。

三大核心创新

Headless 360交付三个层面的创新：

1. 全面API化：100+新工具和技能

Salesforce将其整个平台能力重新暴露为API、MCP工具或CLI命令，涵盖：

  • 数据操作：读写Salesforce记录、字段
  • 工作流自动化：触发Flow、执行审批流程
  • 服务管理：创建/更新案例、派发工单
  • 分析能力：运行报表、查询数据集

这意味着：AI Agent可以像人类一样在Salesforce中完成任何操作，只是更快、更准确且24小时不间断。

2. Agentforce：Agent级别的编排平台

在Headless 360架构之上，Salesforce推出了 Agentforce——一个专门用于构建、部署和管理AI Agent的企业级平台。

关键特点：

  • 多Agent协调：支持Sales（销售）、Service（服务）、Marketing（营销）和Commerce（商务）等多个专业Agent协同工作
  • 系统联动：Slack作为人机协作层，Agent完成工作，人类通过Slack介入审核和决策
  • 企业级管控：权限控制、审计日志、合规保障

3. AgentExchange：10000+应用的应用市场

Salesforce将AgentExchange marketplace打造为AI Agent的"应用商店"：

  • 10000 Salesforce应用
  • 2600+ Slack应用
  • 1000+ Agentforce Agent、工具和MCP服务器

生态数据证明了这一市场的即时价值：

  • Notion：平均销售周期从4个月缩短至3周
  • Docusign：Q4 2025年处理200+私人要约，签署时间减少60%
  • MeshMesh：上市6周即获得首个财富500强客户

技术架构：从UI层到API层的解耦

Headless 360的核心技术变革是彻底解耦UI层与业务逻辑层：

传统模式 Headless 360模式
人类 → 浏览器 → UI → 业务逻辑 Agent → API/MCP/CLI → 业务逻辑
每次操作需要完整渲染界面 直接调用，无需渲染开销
速度慢，无法规模化 毫秒级响应，支持并发

这一转变的深远影响在于：Salesforce不再是一个"应用"，而是一个可编程的企业操作系统——任何AI Agent都可以通过API接入并操作企业数据。

行业意义：企业软件的范式转移

Headless 360代表了企业软件行业的一次范式转移：

从"SaaS应用"到"企业操作系统"

Salesforce不再是人类使用的工具，而是：

  • AI Agent使用的基础设施
  • 企业工作流的编排层
  • 人类与Agent协作的中间平台

这一转变与Anthropic的Claude Code Security、Nature Methods综述中的"人在回路"理念形成有趣的呼应——在Salesforce的新架构中，人类和Agent不是替代关系，而是协作关系：Agent执行，Slack中的人类审核并决策。
