DeepSeek 发布 V4.1-Flash，并称其优于 V4-Pro

📰 SiliconANGLE：DeepSeek releases V4.1-Flash

原文要点

据 SiliconANGLE 报道，DeepSeek 发布了 DeepSeek-V4.1-Flash，并将其称为新架构系列中最小的模型。报道转述 DeepSeek 的说法：多方测试显示，这一开放权重模型在性能、成本、速度和总运行时间上优于规模更大的 V4-Pro；这是厂商主张，未在本文中独立验证。

报道还称，V4.1-Flash 为混合专家模型，总参数量 5520 亿；自 9 月 14 日起，发送至 V4-Pro API 的请求将由 V4.1-Flash 回答，并按较小模型的费率计费，直至 V4.1-Pro 推出。有关迁移安排与指标应以 DeepSeek 官方公告为准。

为什么重要

若厂商以更低成本的模型替换既有 API 路径，用户关注点会从单一基准分数延伸到迁移行为、价格、输出差异与兼容性。对生产系统而言，厂商性能声明应通过自身任务集、延迟和成本数据进行复核。

关键要点

  • DeepSeek 发布 V4.1-Flash，报道称其为开放权重模型。
  • “优于 V4-Pro”的结论为厂商经媒体转述的主张。
  • 报道列示模型总参数量为 5520 亿。
  • V4-Pro API 的路由与计费调整以官方公告为准。
