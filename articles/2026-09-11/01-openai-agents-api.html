OpenAI 推出 Agents API 公测版

📰 OpenAI：Introducing the Agents API

原文要点

OpenAI 宣布将 Agents API 以公开测试（public beta）形式提供给开发者。该 API 让开发者在一次调用中指定任务、模型、工具和运行环境；OpenAI 负责托管与维护 agent harness。开发者可选择 OpenAI 托管沙箱、自有基础设施，或合作伙伴提供的沙箱。

原文还列出面向长时任务的上下文压缩、按需工具搜索、以代码编排工具调用，以及多智能体并行协作等能力。OpenAI 表示，公测期间 API 本身不额外收费，使用者仍按 token 和工具计费。

为什么重要

这把此前需要团队自行搭建的上下文、工具与子智能体编排层打包为平台能力。对希望把智能体用于持续运行工作流的开发者而言，重点不只是模型调用，而是运行环境、状态延续和工具治理是否可被标准化。

关键要点

  • Agents API 目前处于公开测试阶段。
  • API 覆盖任务、模型、工具与运行环境的配置。
  • 支持 OpenAI 托管、自建及合作伙伴沙箱。
  • 提供上下文压缩、工具搜索和多智能体能力。
