NVIDIA RTX Spark：让 Windows PC 本地运行 AI Agent 成为现实的芯片

原文链接：https://blogs.nvidia.com/blog/rtx-ai-garage-computex-spark-local-agents/

为什么重要

NVIDIA 推出 RTX Spark，定位为面向 Windows PC 的本地 AI Agent 专用芯片，终结了"本地运行 AI Agent 性能不够"的传统认知。该芯片采用 GB10 Grace Blackwell Superchip（同 DGX Spark），但面向消费级 Windows 笔记本电脑和紧凑型台式机，是 NVIDIA 对苹果 M 系列和高通 Snapdragon 在 AI PC 市场的直接回应。

关键要点

  • 硬件规格：Blackwell RTX GPU + 6144 CUDA 核心 + 第5代 Tensor Cores，20核 Arm Grace CPU，128GB 统一内存，1 PFLOPS FP4 算力
  • 本地 Agent 能力：RTX Spark 专为私密、安全的本地 Agent 运行设计，1 Petaflop 算力和 128GB 内存满足设备端 Agent 需求
  • Windows 生态系统：ASUS、Dell、HP、Lenovo、Microsoft Surface、MSI 将从 2026 年秋季起推出搭载 RTX Spark 的设备
  • DGX Spark for Linux：面向需要 Linux 环境的开发者，统一大内存、快速计算和 NVIDIA CUDA 生态兼容性
  • H Company 合作：NVIDIA 与 H Company 合作优化 Holo 计算机使用模型，实现 2 倍加速和 35% 内存降低
