SAP Sapphire 2026：微软与 SAP 深化 AI 合作，推出 A2A Agent 间协作与 Microsoft IQ 智能层

原文要点

在 2026 年 5 月的 SAP Sapphire 大会上，微软与 SAP 联合发布了一系列深化企业 AI 合作的公告，核心围绕 Microsoft IQ（统一智能层）和 Agent-to-Agent（A2A）协作。

Microsoft IQ：一个共享智能层，连接三个维度：

  • 人员工作方式（通过 Microsoft Teams 等协作工具）
  • 业务流程（通过 SAP Business AI Platform 和 Joule）
  • 知识激活（通过 SAP 知识图谱与 Microsoft Work IQ）

目标是让 AI 在整个组织中拥有完整上下文，实现真正的企业级 AI。

Agent-to-Agent（A2A）协作：这是本次最重要的产品公告。SAP Joule 和 Microsoft 365 Copilot 之间将实现 A2A 集成，使 Joule 能够在 Microsoft 365 生产力套件中无缝执行 Agentic 流程。例如：

  • 在 Word 中的 Microsoft 365 Copilot 内直接访问 SAP S/4HANA 或 SuccessFactors 的 Joule 技能
  • 自动调度一对一会议等跨系统操作

"Save the bAIkery" AI 沉浸体验：一个以面包店为场景的互动演示，展示如何将 Azure OpenAI、SAP Joule、SAP Cloud ERP、Microsoft Copilot Studio 和 Power BI 无缝整合，呈现 AI 如何嵌入核心业务流程而非浮于顶层。

整合架构：SAP 平台（Joule、AI Platform）与 Microsoft 技术栈（Copilot、Fabric、Teams、Azure）深度对接，支持端到端 AI 转型：数据统一 → 智能应用（通过 Joule 和 Copilot） → 跨系统治理执行。

为何重要

1. 企业 AI 走向系统间 Agent 协作时代

A2A（Agent-to-Agent）集成的发布标志着企业 AI 从"单点工具辅助"演进到"多 Agent 系统间自主协调"。Joule 和 Copilot 能互相调用对方的技能并在各自系统中执行操作，意味着企业工作流可以跨越 SAP 和 Microsoft 两大平台自动编排，大幅减少人工在不同系统间切换的成本。

2. Microsoft IQ 的推出代表企业 AI 架构的思路转变

传统企业 AI 往往是"点解决方案"（单点模型、单点应用）。Microsoft IQ 的思路是构建一个共享智能层，让所有企业 AI 应用共享人员、业务和知识的一致性上下文。这是企业级 AI 能否真正产生规模化价值的关键基础设施。

3. AI 嵌入核心 ERP 系统的趋势进一步确立

SAP 与微软此次展示的不是简单的 API 连接，而是将 AI 能力深度嵌入 ERP 的业务逻辑和语义层。这意味着企业 AI 的下一阶段竞争将不在于"谁有 AI"，而在于"谁能把 AI 无缝部署到核心业务系统"，SAP 和微软的联合显然是这一方向的强力背书。
