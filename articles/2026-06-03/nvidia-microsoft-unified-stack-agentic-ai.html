NVIDIA 与微软联合发布统一技术栈，瞄准 Agentic AI 时代

原文要点

NVIDIA 与微软在 Microsoft Build 大会上宣布了深度合作，旨在为 Agentic AI（自主式 AI）构建从 Windows 设备到 Azure 云再到本地部署的完整全栈方案。核心发布包括：

  • NVIDIA RTX Spark：全球首款专为 AI 代理原生设计的 Windows PC，搭载于笔记本电脑和小尺寸台式机，为本地 AI 代理提供加速算力。
  • DGX Station for Windows：面向企业桌面的 AI 超级计算机，将万亿参数级 AI 能力直接带到每个企业员工的桌面。
  • Microsoft Fabric 加速：NVIDIA GPU 加速的 Microsoft Fabric 数据分析平台，集成 NVIDIA 开放模型于 Microsoft Foundry。
  • NVIDIA OpenShell：安全的 AI 运行时，已整合进 GitHub Copilot，提供沙箱隔离与策略执行能力。
  • 下一代 AI 工厂：黄仁勋（Jensen Huang）在 Build 主题演讲中与微软 CEO 纳德拉（Satya Nadella）共同阐述双方在 AI 工厂基础设施上的合作规划。

关键合作背景：黄仁勋从台北 COMPUTEX 会场远程参加了微软 Build 的主题演讲，凸显了两大生态系统的深度联动。

为什么重要

这次合作代表了 AI 基础设施竞争格局的一次重要演变：不是单纯的模型性能竞争，而是全栈控制权的争夺。

对于企业而言，这意味着几个深刻变化：

  1. AI 代理终于有了原生操作系统层面的支持。过去企业部署 AI 代理需要自己拼凑安全、运行时和基础设施方案；现在 NVIDIA + 微软的组合提供了从芯片到云到桌面的完整路径，降低了企业采纳门槛。

  2. 本地化推理能力真正进入企业视野。RTX Spark 和 DGX Station for Windows 让企业可以在本地运行大规模 AI 代理，不必把所有数据都送到云端，这对于金融、医疗等强监管行业意义重大。

  3. OpenShell 的意义被低估。AI 代理的安全治理一直是企业大规模部署的最大阻力——OpenShell 作为开放的沙箱运行时，并与 GitHub Copilot 深度集成，可能成为企业级 AI 代理安全标准的雏形。

  4. 这不是单一产品的发布，而是生态锁定。当企业同时使用 RTX Spark（硬件）+ DGX Station（算力）+ Microsoft Fabric（数据）+ Azure（云端）+ OpenShell（安全）时，切换成本将极高。

关键要点

  • NVIDIA 与微软的合作伙伴关系覆盖了从设备端（RTX Spark）到桌面端（DGX Station）到云端（Azure）的完整 AI 代理基础设施
  • OpenShell 安全运行时已进入 GitHub Copilot，为 AI 代理提供企业级沙箱和策略控制能力
  • 本地 AI 推理不再是实验性功能，正在成为企业 AI 战略的正式组成部分
  • 黄仁勋与纳德拉的同台体现了 AI 工厂（AI Factory）作为下一代企业基础设施的核心定位
  • 双方合作的核心目标是让开发者能够"原生"在 Windows 生态内构建、调优和运行 AI 代理，而非依赖外部拼凑方案
