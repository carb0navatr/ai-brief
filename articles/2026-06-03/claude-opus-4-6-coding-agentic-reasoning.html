Claude Opus 4.6：Anthropic 发布顶级编码与代理推理模型，百万 token 上下文开启内测

原文要点

Anthropic 发布了 Claude Opus 4.6，这是该公司 Opus 级别的最强模型，主打编码能力和长时代理任务的显著提升：

  • 编码与代理能力全面升级：更精心的规划、更长的代理任务持续性、更大代码库中的可靠运行、更强的代码审查和调试能力，能主动发现自身错误。
  • 100 万 token 上下文窗口（内测）：Opus 系列首次支持百万级上下文，为超长文档分析、跨大型代码库工作提供了技术基础。
  • 业界领先的性能指标：
    • Terminal-Bench 2.0（代理编码评测）：所有模型中最高分
    • Humanity's Last Exam（复杂多学科推理测试）：领先所有前沿模型
    • GDPval-AA（经济价值知识工作评测）：比 GPT-5.2 高约 144 分，比 Opus 4.5 高 190 分
    • BrowseComp（困难信息定位评测）：超越所有其他模型
  • 安全表现达到行业最优：整体安全表现等于或优于行业其他前沿模型，在安全评估中表现出低比例的不对齐行为。
  • Claude Code 新增代理团队（Agent Teams）：支持多个 Claude 实例协作完成任务。
  • API 新能力：Compaction（上下文压缩，让长任务不受 token 限制）、Adaptive Thinking（模型根据上下文线索动态调整推理投入）、Effort 控制（开发者可控制智能、速度和成本之间的平衡）。
  • 日常工作效率工具扩展：Claude in Excel 重大升级，Claude in PowerPoint 进入研究预览阶段。

为什么重要

Claude Opus 4.6 的发布是 Anthropic 在 2026 年企业 AI 竞争中的一次重要布局，其战略含义远超性能数字本身：

  1. 编码代理的格局正在被重新定义。Terminal-Bench 2.0 的最高分和 GDPval-AA 对 GPT-5.2 领先 144 分，意味着 Claude 在需要深度推理+长时执行的编码场景中取得了实质性优势。这对于 Cursor、Windsurf 等以 Claude 作为默认模型的 AI 编程工具提供商有直接影响。

  2. 百万 token 上下文是关键能力，但落地节奏需观察。100 万 token 对于法律文档分析、大型代码库审查、跨文件重构等场景意义重大。但目前处于内测阶段，实际可用性和定价策略尚未明确。

  3. Agent Teams 功能值得关注：这意味着 Claude 不再是单一代理的工作环境，而是开始支持多代理协作——与 Salesforce Agentforce、Microsoft Copilot 等平台的多代理战略形成了直接竞争。

  4. Adaptive Thinking 和 Effort 控制是面向企业定价优化的产品设计：Anthropic 正在让客户自己决定"花多少钱买到多少智能"，这是对用量计费趋势的主动回应，而非被动跟随。

  5. Claude in Excel 和 PowerPoint 的扩展表明 Anthropic 正在从"API 供应商"向"企业应用层"渗透——通过深度集成微软办公套件进入数亿用户的日常工作流。

关键要点

  • Claude Opus 4.6 在编码代理评测和长任务执行上取得业界领先成绩，GDPval-AA 比 GPT-5.2 高约 144 分
  • 100 万 token 上下文窗口进入内测，为超长任务提供技术基础
  • Claude Code 新增 Agent Teams 功能，支持多代理协作架构
  • Compaction、Adaptive Thinking、Effort 控制等新能力赋予开发者更细粒度的智能/成本控制
  • Anthropic 正通过 Excel 和 PowerPoint 集成向企业应用层深度渗透
