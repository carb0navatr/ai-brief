AWS 展示 OpenClaw 接入 AgentCore 的受限支付方案

📰 AWS Machine Learning Blog

AWS 与 OpenClaw Foundation 发布集成指南，说明 OpenClaw 智能体如何通过 Amazon Bedrock AgentCore payments 处理需 HTTP 402 付费的服务。示例使用 x402 v2：由人工在受信任的管理路径中创建钱包和支付会话，智能体运行时只能在预先定义的收款方、资产、网络、单笔金额、累计预算及有效期限制内发起付款。

关键要点

  • 集成使用 aws-agents-pay 插件，向模型暴露会话状态查询和获取已批准付费内容两项工具。
  • 钱包凭证与创建、延长支付会话的权限不放在模型可见运行时；运行时不能扩大授权范围。
  • 插件会核验 HTTP 402 挑战的资源、网络、资产、收款方和金额，并采用幂等令牌降低重复支付风险。
  • 文中演示支持 Coinbase 钱包或 Stripe Privy 钱包连接，并以 Base Sepolia 作测试示例。

为什么重要

支付让智能体从“调用免费工具”走向可完成付费服务流程，但也把提示注入、越权消费和凭证泄露的风险带入运行环境。该方案的核心价值不在于让模型自由付款，而在于将支付权限压缩为可审计、可撤销、有限额的能力边界，为面向 API、内容和 MCP 服务的智能体交易提供一种工程实现路径。
