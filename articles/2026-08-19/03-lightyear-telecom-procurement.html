Lightyear 发布电信采购智能体平台，瞄准报价与装机流程

📰 Fierce Wireless

企业电信采购平台 Lightyear 发布智能体式 AI 平台，将网络服务采购、报价和实施中的部分流程自动化。平台包括负责信息查询的 Dispatch，以及 Quoting Agent 和 Implementation Agent。

原文要点

  • Dispatch 可回应企业关于网络资产、合同续约、高于市场水平的费率及备用连接缺失等自然语言问题；Lightyear 称，早期用户以两次提示、约一分钟的中位时间生成资产与支出报告。
  • Quoting Agent 基于客户需求、采购规则和平台价格数据筛选运营商并发出询价。公司称其出价返回速度提高 30% 至 50%，合格报价数量提高 15% 至 25%。
  • Implementation Agent 读取平台数据、项目更新与邮件线程，对照运营商承诺的里程碑发现延误；公司称其可将安装时间缩短 5 至 10 天。
  • Lightyear 表示智能体须在客户设定规则下工作，部分操作会暂停并要求人工批准；其训练数据来自自 2019 年以来积累的逾 200 万份报价、覆盖 1,200 家运营商。

为什么重要

智能体正在从运营商网络侧的运维自动化，延伸到企业侧的采购与供应商管理。该案例显示，真正可落地的行业智能体往往依赖专有流程数据和明确的审批边界，而非通用对话能力。文中百分比均为公司陈述，采购团队仍需在成本、报价质量、供应商覆盖和审批责任上独立评估。

关键要点

  • 产品覆盖询价、实施跟踪等电信采购环节。
  • 性能改善数据由 Lightyear 提供，应结合实际部署验证。
  • 人工审批仍被保留在部分动作之前。
