NVIDIA 发布企业级 AI Agent 工具包，瞄准长期运行智能体基础设施

为什么重要

NVIDIA 在 2026 年 Computex 台北大会期间宣布了完整的企业 AI Agent 软件栈，包括开源模型、工具包和安全运行时。这不仅是技术发布，更代表 AI 从「单次问答」走向「长期自主运行」的范式转变——企业软件巨头（Cadence、Siemens、Synopsys 等）正用这些工具构建能够替代工程师执行仿真验证的 AI 同事，将数周的工程周期压缩至数小时。

关键要点

  • NemoClaw 蓝图 + OpenShell 安全运行时：开源工具包帮助企业构建安全的长期运行 AI Agent，Cadence 已用其构建 ChipStack AI 超级代理，自主完成芯片设计与验证，NVIDIA 自身成为首个客户。
  • Nemotron 3 Ultra 模型：5500 亿参数的混合专家模型，专为长期运行 Agent 设计，推理速度提升 5 倍，成本降低 30%；已针对主流 Agent 框架（LangChain、OpenHands 等）优化。
  • 工业软件巨头全面入局：Cadence（西门子）、Dassault Systèmes、Siemens、Synopsys 均使用 NemoClaw 构建自主 AI 工程师；Foxconn 用其驱动临床推理和工厂运营 Agent。
  • OpenShell 生态扩展：微软、Canonical、Red Hat、SAP、ServiceNow 均已集成 OpenShell，为 AI Agent 提供身份认证、隔离、策略和端到端安全控制。
  • CUDA-X 库作为 Agent 技能：cuDF（数据处理）、cuOpt（路径优化）、AI-Q（智能路由）等专业库现已作为 Agent 技能开放，扩展 Agent 在科学和工程领域的能力边界。
