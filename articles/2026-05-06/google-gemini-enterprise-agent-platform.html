Google 推出 Gemini Enterprise Agent Platform：Vertex AI 的全面升级

原文要点

  • Google 在 Cloud Next 2026 大会上发布 Gemini Enterprise Agent Platform，取代 Vertex AI，成为企业 Agent 开发的新标准
  • 新平台定位为"企业 AI 的控制塔"，提供构建（Build）、扩展（Scale）、治理（Govern）、优化（Optimize）四大能力
  • 整合了 Vertex AI 的模型选择和模型构建能力，新增 Agent 集成、DevOps、编排和安全功能
  • 提供统一的开发者体验：Vertex AI Workbench 升级、Vertex AI Agent Builder 用于可视化编排、Code Assistant for Agents 提供 AI 辅助编程
  • 安全与治理功能包括：Vertex AI Agent Security（扫描漏洞、阻止敏感数据外流）、Vertex AI Agent Gateway（集中管理、监控、合规）、IAM 集成、基于角色的访问控制、数据加密
  • Agent Observability 提供对话追踪和实时调试能力，Agent Optimizer 自动聚类真实失败案例并提出改进建议
  • 通过多模态 AutoRaters 评估 Agent 逻辑，基于真实流量持续评分

深度解读

Vertex AI 的退休和 Gemini Enterprise Agent Platform 的推出，标志着 Google 在企业 AI 战略上的重大转向：从"机器学习平台"到"Agent 操作平台"。这不仅仅是品牌重塑，而是认知的重构——企业需要的不是训练模型的工具，而是运行 Agent 的基础设施。

平台的四大能力（构建、扩展、治理、优化）形成完整闭环。企业可以从小规模试点开始，逐步扩展到生产级别的 Agent 部署，同时保持安全和合规控制。这解决了一个核心矛盾：AI Agent 的灵活性 vs. 企业需要的安全保障。

Vertex AI Agent Security 的扫描和防护能力是关键。AI Agent 比传统软件更容易产生"意外行为"——模型可能生成敏感内容、被恶意提示词注入、或在多步推理中产生偏差。如果没有专门的Security 层，企业无法放心将 Agent 用于真实业务场景。

Agent Observability 和 Agent Optimizer 的组合是另一个亮点：观察能力让团队看到 Agent 在做什么，优化能力让 Agent 越变越好。这将 Agent 开发从"一次性项目"变成"持续改进的循环"——对于追求 AI 落地的企业来说，这种持续优化的机制至关重要。

与 Anthropic 的 Claude Managed Agents 和 OpenAI 的 Frontier 相比，Google 的优势在于生态整合： Gemini Enterprise Agent Platform 与 Google Cloud 的其他服务（BigQuery、Looker、Apigee）天然集成，让已经使用 Google Cloud 的企业可以快速扩展 Agent 能力。这是一场企业级 AI 基础设施的竞争，而 Google 正在用"一站式平台"来争取更多份额。
