Microsoft 发布 E7 Suite 与 Copilot Cowork：十年来最大企业授权变革

原文要点

  • Microsoft 365 E7 Suite 将于 2026 年 5 月 1 日正式发布，含 Teams 定价 $99/用户/月，不含 Teams 定价 $90.45/用户/月
  • 这是微软约十年来首次发布新的企业授权计划，将 E5、M365 Copilot、Agent 365 等产品统一整合到 E7
  • 发布与 Anthropic 合作的 Copilot Cowork 研究预览版，基于 Claude 模型
  • Agent 365 控制平面同日GA，包含 Agent 注册表、安全策略模板、性能报告、采用率追踪等功能
  • Entra 能力让每个 Agent 拥有唯一身份，支持基于风险、设备合规性、自定义安全属性的实时访问决策
  • Defender 和 Purview 的风险信号评估仍处于公开预览阶段
  • 约 50 万渠道合作伙伴生态将参与 E7 推广

深度解读

E7 的发布是微软企业策略的重大调整。十年来首次新的企业授权计划，意味着微软正在重新定义"企业 AI 包"的边界——不是单独的 Copilot、单独的 Agent 365，而是打包成完整的企业 AI 操作系统。

$99/用户/月的定价（E7 含 Teams）值得关注。考虑到 E7 整合了 E5 的全部能力、M365 Copilot 的 AI 功能和 Agent 365 的 Agent 管理能力，这个价格实际上比分别采购更低。这是一种典型的"捆绑订阅"策略：用更低的感知价格让企业绑定微软生态，提高切换成本。

Copilot Cowork 是微软与 Anthropic 合作的产物——这是微软在 AI 竞争中寻求平衡的信号。与 Anthropic 合作意味着微软认识到 Claude 在某些场景下的优势；选择合作而非竞争，展示了务实的企业战略。Copilot Cowork 不会削弱 Microsoft Copilot，而是与它协同——Claude 驱动的 Cowork 可以处理需要深度推理的任务，而 Copilot 处理日常生产力场景。

Agent 365 的安全能力是 E7 的核心差异点之一。Agent 注册表、安全策略模板、Entra 集成的身份管理——这些功能让 IT 团队能够真正治理 AI Agent 的行为。对于担心 AI Agent "失控"的企业来说，这些治理工具是采用的前提条件。

微软通过 E7 传递的信息很清晰：企业不需要东拼西凑地采购 AI 工具，微软可以提供一站式解决方案。约 50 万渠道合作伙伴是这一策略的执行力量——他们将在企业推广中扮演关键角色。微软正在用生态力量对抗 Anthropic 和 OpenAI 的技术冲击。
