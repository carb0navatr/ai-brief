Holo3.1 发布：快速本地推理的计算机控制代理

为什么重要

H Company 发布 Holo3.1，在此前业界领先的 Holo3 基础上，进一步提升了对 Web、桌面、移动等多端 GUI 环境的鲁棒性，并首次支持量化权重（FP8、Q4 GGUF、NVFP4），实现在消费级硬件上的完全本地化 AI 代理运行。这标志着计算机使用代理从云端部署向端侧落地的关键一步，对于注重数据隐私和降低推理成本的企业用户意义重大。

关键要点

  • 移动端性能大幅提升：在 AndroidWorld 基准上，35B-A3B 模型从 67% 提升至 79.3%，4B 和 9B 小模型从 58% 提升至 72%。
  • 跨框架原生支持：除原有结构化 JSON 输出外，新增对 Function Calling 协议的原生日志支持，Holo3.1 在 OSWorld 和企业级电商、协作工作流等内部基准上提升超过 25%。
  • 四款规模可选：Holo3.1-0.8B（超轻量本地代理）、Holo3.1-4B（成本效益部署）、Holo3.1-9B（性能延迟平衡）、Holo3.1-35B-A3B（最高性能）。
  • 本地高速推理：在 DGX Spark 上，NVFP4 W4A16 配置实现比 BF16 高 1.74 倍的 token 吞吐；结合代理框架优化，端到端平均步进时间从 6.8 秒缩短至 3.3 秒。
  • 完全私有化：代理完全在本地 Windows 或 Mac 机器运行，模型可在同设备或同网络 DGX Spark 上执行，所有数据不离开用户网络。
