1. OpenAI 向欧盟开放网络攻击模型

为什么重要

OpenAI 主动向欧盟提供其最新的 GPT-5.5-Cyber 网络攻击模型预览权限，展现出高度透明的监管合作姿态。而 Anthropic 却在同一问题上保持距离，Mythos 发布一个月后仍未向欧盟提供预览。这种对比可能影响两家公司在监管最严格市场的竞争地位。

关键要点

  • OpenAI 周一宣布将向欧盟及其成员国的企业、政府和网络安全机构提供 GPT-5.5-Cyber 的访问权限

  • 欧盟委员会发言人 Thomas Regnier 表示欢迎 OpenAI 的透明举措，称这将"让我们能够密切关注模型的部署"

  • Mythos 同样发布于一个月前，引发了关于网络攻击的担忧，但 Anthropic 尚未向欧盟提供预览访问

  • Anthropic 与欧盟的讨论"处于不同阶段"，双方已进行了"四五次会议"，但尚未达成与 OpenAI 同等的协议

  • OpenAI 强调"AI 实验室不应成为网络安全的唯一仲裁者"，并推出"OpenAI 欧盟网络行动计划"

  • Anthropic 尚未对此发表评论

3. 1800 多台 MCP 服务器暴露于互联网

为什么重要

MCP（Model Context Protocol）作为连接大语言模型与外部工具的核心协议，正以惊人的速度被企业采用。然而安全研究显示，1800 多台 MCP 服务器毫无保护地暴露在公网上，且验证样本显示 100% 的服务器允许完全未认证的访问。这暴露了 AI Agent 采用速度与安全成熟度之间的巨大鸿沟。

关键要点

  • Knostic 安全研究人员在 2024 年夏季发现了 1862 台暴露的 MCP 服务器

  • 验证 119 个实例后发现，每个服务器都允许完全未认证的访问

  • 这些服务器可能让攻击者进行"Rug Pull"攻击：替换工具、操纵数据、执行未授权操作

  • 传统的安全架构对这类独特威胁防护不足

  • 云安全联盟（CSA）在 2026 年 2 月发布了《Agentic Trust Framework》，为 AI Agent 安全提供了基础原则：

  • AI Agent 需要像人类用户一样严格的身份治理

  • 无隐式信任，每次交互都需认证和授权

  • 推理与行动严格分离

  • 两家 AI 实验室都在以惊人速度融资，同时筹备 IPO

为什么重要

五角大楼与包括 OpenAI、Google、Microsoft、Amazon、Nvidia、Oracle、SpaceX 和 Reflection AI 在内的八家公司签署了 AI 协议，但明确将 Anthropic 排除在外，理由是"供应链风险"。这一决定可能与此前国防部长 Pete Hegseth 称 Anthropic CEO Dario Amodei 为"意识形态疯子"有关。

关键要点

  • 国防部将 Anthropic 标记为"供应链风险"，此前发生过合同纠纷

  • Anthropic 的 Claude 模型曾通过 Palantir Maven 平台在五角大楼机密环境中使用

  • 此前 Claude 模型曾在伊朗冲突和委内瑞拉马杜罗目标行动中使用

  • 参与公司表示技术不会用于大规模监控或自主武器系统

  • 国防部表示此类用途"违法"，已要求参与公司信任其监督机制

  • 目前尚未公开独立的执行机制

6. AI Agent "Mona" 接管斯德哥尔摩实验咖啡馆

为什么重要

旧金山初创公司 Andon Labs 在斯德哥尔摩开设的实验性咖啡馆，由名为"Mona"的 AI Agent 完全负责运营决策。尽管人类咖啡师仍在冲泡咖啡，但 AI 负责从招聘到库存管理的几乎所有其他事务。这个实验揭示了当前 AI Agent 在实际业务运营中的能力与局限。

关键要点

  • Mona 由 Google Gemini 驱动，负责咖啡馆的招聘、库存管理、合同签订等运营决策

  • 自 4 月中旬开业以来，咖啡馆销售额已超过 5700 美元，但原始预算 21000 美元仅剩不到 5000 美元

  • AI 遇到了典型问题：订购了 6000 张餐巾纸、4 套急救箱和 3000 只橡胶手套，以及咖啡馆不使用的罐装番茄

  • 面包订单问题尤其严重：有时订购过多，有时错过面包店每日截止时间

  • 团队认为问题源于 AI 助手的"有限上下文窗口"，当旧记忆超出上下文窗口时，她会完全忘记之前的订单

  • 咖啡师认为"所有工人基本安全"，"应该担心就业的是中层管理人员"

9. Microsoft Agent 365 正式发布

为什么重要

Microsoft Agent 365 从预览版转为正式可用，标志着企业 AI Agent 管理进入新阶段。随着 AI Agent 数量激增且跨越应用、端点和云端，传统的可见性和控制手段已不足够。Agent 365 提供了统一的安全与治理控制平面。

关键要点

  • AI Agent 的问题不在于其存在，而在于其快速扩散的特性

  • 当 Agent 可以调用工具、访问数据并与其他 Agent 交互时，任何"有用"的工作流都可能转变为数据过度共享、工具滥用或权限过度授予

  • Agent 365 现已扩展到 Microsoft Entra 网络控制，覆盖 Microsoft Copilot Studio Agent 和本地 Agent（如 OpenClaw）

  • 新功能包括：影子 AI 发现、Agent 注册表与身份、Agent-to-Agent 编排、Entra 网络控制扩展

  • 允许安全团队检查 Agent 流量、限制连接仅限批准的目的地、过滤风险文件移动

  • 还可帮助阻止恶意基于提示的攻击

  • 可通过 Microsoft 365 管理中心管理运行在 Windows 365 for Agents 上的 Agent

11. Anthropic 与 FIS 合作推出金融犯罪 AI Agent

为什么重要

FIS 与 Anthropic 合作推出的"金融犯罪 AI Agent"将传统的反洗钱调查流程从数小时压缩到数分钟。这标志着 AI Agent 在受监管的金融环境中的实际应用迈出重要一步，BMO 和 Amalgamated Bank 将率先部署。

关键要点

  • 功能：系统自动收集银行系统中的证据，根据已知洗钱模式检查活动，并标记高风险案例供审查

  • 首批部署方：BMO 和 Amalgamated Bank 将首先部署，2026 年下半年全面上市

  • 合作模式：Anthropic 将其 Applied AI 团队和前置部署工程师嵌入 FIS，帮助设计和开发未来的 AI Agent

  • 技术架构：结合 FIS 的银行基础设施、交易数据和合规系统与 Anthropic 的 Claude AI 模型

  • 数据安全：客户数据将保留在 FIS 控制的基础设施内

  • Anthropic 金融服务业主管 Jonathan Pelosi 表示，Claude 被选中是因为它能"准确推理复杂调查、解释其工作，并在受监管工作流中安全运行"

  • FIS CEO Stephanie Ferris 称这证明了"agent-first 银行未来"架构的可行性
