1. SocialReasoning-Bench：AI Agent 能否站在用户立场行事？

为什么重要

当 AI Agent 越来越多地代表用户执行日历协调、购物谈判等真实任务时，单纯的"任务完成"已不够——Agent 是否真正维护用户利益，成为衡量其可信度的关键指标。SocialReasoning-Bench 是首个系统性评估这一能力的大型 benchmark，直接影响 AI Agent 的产品化可信度标准。

关键要点

  1. 测试场景：基准评估 AI Agent 在两类真实场景中的表现——日历协调（多参与者时间协商）和市场谈判（买卖双方价格博弈），均需平衡自身用户利益与其他方诉求。

  2. 双重评分维度：每项任务同时考察结果最优性（Outcome Optimality，用户实际获得的价值）和尽职调查（Due Diligence，Agent 是否遵循了合理的决策流程，如收集信息、主动还价）。

  3. 前沿模型普遍"留有余地"：当前最强模型通常能完成任务，但在日历协调中接受非最优会议时间，在谈判中接受较差交易价格，未能充分为用户争取利益——这是行为策略问题，而非能力不足。

  4. 即使明确提示"为用户利益行动"，表现仍未达标：研究人员通过 prompt 要求 Agent 优先考虑用户利益，但性能仍远低于可信赖委托人所应达到的水平，说明这不是简单提示能解决的。

  5. 过程质量帮助区分"运气"与"能力"：结合结果分和过程分可发现，部分 Agent 靠"幸运"拿到好结果（低 Due Diligence），部分则有诚意但能力不足（高 Due Diligence 但低 Outcome），两类问题需要不同的改进路径。

2. Vega：AI 时代用零知识证明保护数字身份

为什么重要

AI Agent 越来越多地代表用户与第三方服务交互，用户需要一种方式证明"我是我"、"我是成年人"、"我有执业资质"，而不必暴露身份证件本身。Vega 来自微软研究院，解决了这一核心隐私难题，其零知识证明生成速度已达到实用级别（<100ms），为 AI 时代的身份验证基础设施提供了新范式。

关键要点

  1. 隐私优先的身份证明：用户可凭政府签发的身份证件（驾照、护照等）生成零知识证明，仅透露"我年满 18 岁"或"我是持证医师"，无需暴露证件本身或任何其他信息。

  2. 速度达到实用级别：在普通消费设备上，零知识证明生成时间低于 100 毫秒，且无需"可信初始化"（trusted setup），降低了部署门槛。折叠复用（Fold-and-reuse）机制使同一证明的第二次展示跳过大部分计算。

  3. 兼容真实凭证格式：针对移动驾照（mDL）和欧盟数字身份钱包（EUDI Wallet）等真实政府数字凭证标准设计，而非实验室理想化模型。

  4. 设备绑定防滥用：零知识证明必须与持有设备的签名绑定，防止泄露凭证被他人或未授权 AI Agent 冒用。设备私钥存储于手机安全元件（secure element），无法被软件提取。

  5. 开源即将发布：Vega 采用 Rust 实现，相关证明系统已以开源项目 spartan2 形式发布，完整论文也将发布。这对 AI Agent 开发者的身份集成有直接参考价值。

6. Nemotron-Labs Diffusion：NVIDIA 扩散模型实现光速文本生成

为什么重要

NVIDIA 发布的 Nemotron-Labs Diffusion 语言模型系列，将扩散模型（Diffusion Model）首次以可用方式引入纯文本代。与传统自回归（AR）模型不同，扩散模型通过逐步去噪生成文本，支持自推测（Self-Speculation）加速，在 B200 GPU 上达到约 865 tokens/秒——比同硬件的自回归基线快约 4 倍。这为 AI Agent 的推理速度优化提供了一条全新的工程路径。

关键要点

  1. 三种生成模式合一：该模型系列支持三种生成模式——纯自回归（与传统模型兼容）、Diffusion 模式（快速批量生成）和自推测模式（同一模型即作草稿又作验证器）。

  2. Diffusion 模式（FastDiffuser）：模型每次迭代填充一个 32 token 块，通过置信度阈值决定哪些 token"足够好"可以提交。适合需要批量输出的场景。

  3. 自推测模式（LinearSpec）——速度表现最优：同一模型双向草稿生成，然后因果验证，前缀匹配部分直接提交。在 B200 上达到约 865 tokens/秒，比自回归基线快约 4 倍，且在 temperature=0 时输出与 AR 完全一致（无损）。

  4. 工程可行性：模型已开源，可通过 SGLang 部署，提供了完整的训练配方和技术报告。对需要低延迟推理的 Agent 应用（如实时对话、工具调用）有直接价值。

  5. 开放模型+熟悉接口：开发者无需修改应用程序，即可将扩散解码加速集成到现有 pipeline，降低了实验门槛。
