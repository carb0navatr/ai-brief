4. Causal Tongue-Tie：LLM 能编码因果方向，但其 Yes/No 输出无法表达

为什么重要

这项来自因果推理领域的研究揭示了大语言模型中的一个深层矛盾：模型内部能编码正确答案，但输出接口无法正确表达。具体而言，即使探针（probe）可以从 LLM 的隐藏状态中准确恢复因果问题的答案（准确率约 97%），模型通过 Yes/No 回答时却退回到了"常识性"答案（准确率约 50%）。这对 AI Agent 的推理可靠性有重要启示：在设计 Agent 的输出机制时，不能假设"模型知道 → 模型会说对"。

关键要点

  • 研究发现 LLM 内部状态对因果方向的编码准确率可达约 97%，但通过 Yes/No 回答时仅约 50%（接近随机猜测）

  • 这一 ~47% 的差距被研究者称为"Causal Tongue-Tie"（因果舌打结）现象

  • 失败可分解为两个独立因素：内部没有信号 vs. 内部有信号但输出接口无法表达

  • 对于仅依赖输出准确率的因果推理 benchmark，需要重新审视"答对=理解因果"的假设

  • 研究提示在设计 Agent 的推理模块时，需要区分"模型内部推理能力"与"输出表达能力"，二者不可混同

  • 方法使用固定线性探针从隐藏状态恢复答案，结果的可靠性较高
