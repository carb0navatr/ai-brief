🔥 Anthropic 推出 10 个金融领域 AI Agent，进军企业级市场

产品发布 来源: Anthropic 官方 / Reuters / WSJ / Fortune | 日期: 2026-05-05

Anthropic 于今日正式发布 10 个专门针对金融服务和保险行业的 AI Agent 模板，这是 Claude 模型在企业级垂直领域的重大布局。功能包括构建 pitchbooks、起草信用备忘录、执行审计分析等。Goldman Sachs、Visa、Citi、AIG 等顶级金融机构已宣布采用。在 Vals AI 的 Finance Agent 基准测试中得分 64.37%，行业领先。同日宣布与 Blackstone、Hellman & Friedman、Goldman Sachs 建立新的企业 AI 服务公司。

🤝 AWS 与 OpenAI 扩大战略合作伙伴关系

合作伙伴 来源: AWS 官方 / OpenAI 官方 / About Amazon | 日期: 2026-04-28 ~ 2026-05-05

AWS 与 OpenAI 宣布扩大战略合作伙伴关系，这是 OpenAI 首次将其最新模型通过第三方云服务商提供。OpenAI 模型（包括 GPT-5.5、GPT-5.4、Codex、Managed Agents）将在 Amazon Bedrock 上提供预览。双方还推出 Amazon Bedrock Managed Agents 服务和 Codex on Amazon Bedrock。这标志着 OpenAI 从消费级向企业级市场的重要转型，也打破了与 Microsoft Azure 的独家合作关系。企业现在可以在 AWS 环境中安全地构建 AI 应用。

⚖️ Musk vs Altman 诉讼审判进入第二周

法律动态 来源: The Verge / NYT / CNBC / MIT Technology Review / Reuters / CNN / Business Insider | 日期: 2026-05-04 ~ 2026-05-05

Elon Musk 起诉 OpenAI、Sam Altman 和 Greg Brockman 的诉讼正式进入审判第二周。Greg Brockman 作证称他是 OpenAI 最大的个人股东之一，持股价值约 300 亿美元。Brockman 还透露 Musk 在 2018 年离开 OpenAI 时曾表示将在 Tesla 内部建立 AGI 竞争对手。Musk 在审判前两天联系了 Brockman 试探和解意向。Sam Altman 曾担心 Musk 会在审判前撤诉，使 OpenAI 没有机会陈述自己的观点。这是 AI 行业历史上最受关注的法律案件之一，审判正在 YouTube 上全程直播。
